## 1. 인터랙티브 스타일 카탈로그

링크: `https://poster-style-catalog.vercel.app`

64개 디자인 스타일을 한 화면에서 비교하는 대시보드.

- 스타일마다 실제 예시 이미지 + 컬러 팔레트 + 추천 폰트 3종 (Google Fonts 링크 포함)
- 카드마다 **복사용 프롬프트 내장** — 빈칸(브랜드명·헤드라인·컬러·씬)만 채우면 미드저니 등에 바로 사용
- 검색 · 카테고리 필터 · 후보 담기 지원

## 2. 스킬 설치

파일: `campaign-poster-design-skill.zip`

| 환경 | 방법 |
|---|---|
| Claude Code | `~/.claude/skills/` 에 압축 해제 → `~/.claude/skills/campaign-poster-design/SKILL.md` 가 되도록 |
| claude.ai (웹) | Settings → Capabilities → Skills → Upload skill → zip 그대로 업로드 |

설치 후 "포스터 만들어줘"로 자동 발동.

## 3. 프롬프트 사용법

| 상황 | 입력 |
|---|---|
| 최소 | `[제품 사진 첨부] 포스터 만들어줘` |
| 권장 | `[제품 사진 첨부] 이 제품으로 신제품 출시 인스타 피드용 포스터 만들어줘. 차분하고 럭셔리한 느낌으로.` |
| 스타일 지정 | `Risograph 스타일로 포스터 만들어줘` |
| 프롬프트만 수령 | `포스터 프롬프트만 줘` |

Claude가 처리하는 순서: 무드 분석 → 64개 중 스타일 1개 선택 → 레이아웃(10종)·폰트 매칭 → 프롬프트 조립 → 생성

## 4. 이미지 생성 연동

| 방식 | 설명 |
|---|---|
| Higgsfield MCP (권장) | 계정 연결 시 스킬이 생성까지 자동 수행 |
| Gemini API | `GOOGLE_API_KEY` 있으면 로컬 생성 |
| 연동 없음 | 프롬프트만 받아 미드저니·드리미나 등에 붙여넣기 |

---

## 5. 핵심 원칙 (원문 강조)

> **레이아웃 먼저 정하고, 텍스트 얹기.**
> 이미지 먼저 만들고 글자를 얹으면 무조건 스티커 티가 난다.
> 프롬프트에 **"왼쪽 위 1/3은 헤드라인 자리로 비워줘"** 한 줄이면
> 이미지가 글자 자리를 만들며 태어난다.

## 우리 적용

→ [`../content-workflow.md`](../content-workflow.md) §5

이번 레퍼런스 3건 중 **가장 실용적인 한 줄**이다. 세 곳에 적용한다.

**① AI 이미지 생성 프롬프트**
글자 자리를 먼저 지정한다.
```
leave the top-left third as empty negative space for a headline
```

**② 카드 디자인**
1080×1080 그리드에 텍스트 블록을 먼저 배치한 뒤 배경을 채운다.
[`../design-system.md`](../design-system.md)의 SVG 5종이 이미 이 방식으로 만들어졌다 —
딥 잉크 배경 위에 96px 여백과 88px 행간으로 텍스트 자리를 먼저 잡고 요소를 얹었다.

**③ 세로 영상**
상단 1/3은 인물·제품, 하단 안전영역은 자막. [`../storyboard.md`](../storyboard.md)의
"얼굴·카드가 화면 상단 1/3에 오도록, 자막은 하단 안전영역" 규칙과 동일한 원리다.

**참고 — 스타일 카탈로그**
64개 스타일 대시보드는 우리 카드 디자인의 대안을 탐색할 때 쓸 수 있다.
다만 현재 우리 시각 시스템(딥 잉크 + 앰버)은 **토스 공식 브랜드로 오인되지 않도록**
의도적으로 설계한 것이므로, 스타일을 바꿀 때도 이 제약을 먼저 확인해야 한다.
