# TOSS 광고 스토리보드 — 우측 공간축·일본인 관광객 교체 설계

작성일: 2026-07-18
상태: 사용자 방향 승인, 구현 전 서면 검토 대기

## 1. 목표

기존 13컷 세로형 스토리보드의 이야기와 한국 지하철 미술 방향은 유지하면서 다음 세 가지 문제를 해결한다.

1. 관광객을 사용자가 제공한 `Photo 1.jpg`의 동일 인물로 전 컷 교체한다.
2. S06과 S08을 개찰구 정면축이 아닌, 개찰구를 정면으로 본 상태에서 시선을 오른쪽으로 약 90° 돌렸을 때 이어지는 역사 측면 공간으로 재설계한다.
3. S12에서 심판이 개찰구 오른쪽에 서서 시계가 없는 오른손으로 TOSS 카드를 태그하도록 손 방향을 바로잡는다.

## 2. 고정 요소

### 관광객 캐릭터 락

- 얼굴과 헤어 아이덴티티는 사용자가 마지막으로 제공한 `Photo 1.jpg`를 기준으로 한다.
- 앞머리가 있는 곧은 짙은 갈색 중간 길이 머리, 자연스러운 메이크업, 부드럽고 단정한 인상을 전 컷에서 동일하게 유지한다.
- 국적 표현은 과장된 표식이나 고정관념 대신 캐스팅, 헤어, 메이크업, 여행 소품으로 전달한다.
- 기존 연속성을 위해 흰색 루즈 블라우스, 연청 바지, 베이지 크로스백, 베이지 플랫슈즈, 은색 하드 캐리어는 유지한다.
- 신장, 체형, 머리 길이, 가방 끈 방향, 캐리어 손잡이와 바퀴 수를 컷마다 바꾸지 않는다.

### 심판 캐릭터 락

- 기존 `referee_lock_A.png`의 얼굴, 체형, 검정·흰색 줄무늬 셔츠, 검정 반바지, 니삭스, 검정화, 호루라기를 유지한다.
- 검정 시계는 항상 왼쪽 손목이다.
- TOSS 카드 꺼내기와 태그는 항상 오른손이다.

### 지하철 공간 락

- 서울 지하철형 회색 타일, 스테인리스 마감, 파란 안내판, 주백색 천장 조명과 기존 색보정을 유지한다.
- 기존 개찰구 정면축은 A01–A03으로 유지한다.
- 새로운 우측 측면축은 A04로 분리해 S06과 S08이 공유한다.

## 3. 신규 공간 앵커 A04

파일 예정 위치: `edit/storyboard_gpt2/anchors/A04_right_concourse_master.png`

- 카메라 위치는 관광객이 멈춘 G3 개찰구 앞이며, 렌즈 방향만 개찰구 정면에서 오른쪽으로 약 90° 회전한다.
- 화면에는 개찰구 정면이나 반복되는 게이트 열이 보이지 않는다.
- 대신 우측 역사 통로의 회색 타일 기둥, 파란 노선·출구 안내판, 벽면 지도, 멀리 이어지는 복도와 천장 조명 리듬을 보여준다.
- 공간 깊이는 심판이 6–8m 거리에서 관광객을 향해 걸어올 수 있을 만큼 확보한다.
- 관광객과 심판이 없는 빈 마스터 배경으로 먼저 생성한다.
- 기존 공간과 조명·재료·색온도는 같되, 구도는 명확히 다른 방향이어야 한다.

## 4. 컷별 변경

### S06 — 정체 공개 / 첫 접근

- 카메라는 관광객의 뒤쪽 왼편에 위치한 오버더숄더다.
- 관광객의 새 머리 뒤통수와 왼쪽 어깨가 화면 왼쪽 전경 20–25%를 차지한다.
- 초점은 6–8m 앞의 심판에게 맞춘다. 심판은 화면 중앙보다 약간 오른쪽에서 관광객을 바라보며 첫발을 내딛는다.
- 배경은 A04 우측 측면 통로이며 개찰구, `타는 곳` 대형 간판, 반복 게이트 열은 보이지 않는다.
- 관광객의 시선과 심판의 진행선이 한 축으로 맞아야 한다.

### S08 — 성큼성큼 접근

- A04와 동일한 통로, 동일한 진행축을 사용한다.
- S06보다 카메라를 낮추고 10–15% 가까이 당겨 심판의 보폭과 압박감을 키운다.
- 관광객의 흐린 뒤통수 오른쪽 가장자리와 왼쪽 어깨를 화면 왼쪽 폭의 8% 이내로 남겨 심판이 누구를 향하는지 증명한다.
- 심판은 엄숙한 표정으로 중간 보폭에 있으며 전신과 신발이 모두 보여야 한다.
- 배경에 개찰구가 다시 등장하거나 심판이 카메라만 향해 걷는 무맥락한 패션 워크처럼 보여서는 안 된다.

### S12 — 오른손 성공 태그

- 리더기는 화면 왼쪽, 심판의 몸은 화면 오른쪽에 둔다.
- 심판의 시계 없는 오른손이 화면 오른쪽에서 왼쪽으로 뻗어 정확한 TOSS 카드 한 장을 리더기에 태그한다.
- 시계가 찬 왼팔은 몸 옆으로 내려가며, 프레임 가장자리에서 왼쪽 손목 시계가 확인되도록 한다.
- 극단적 매크로 대신 손 소유권을 확인할 수 있는 3/4 미디엄 클로즈업을 사용한다.
- 녹색 성공 링, 정확한 카드 전면, 자연스러운 손가락 수와 카드 접촉면을 유지한다.
- 왼손 태그, 시계가 카드 손에 붙는 장면, 좌우 반전, 중복 손·카드를 금지한다.

## 5. 관광객 교체 범위

관광객이 보이는 A02, A03 및 S02, S03, S04, S06, S07, S09, S10의 전경 일부, S13을 새 캐릭터 락으로 갱신한다. S01, S05, S11, S12처럼 관광객 얼굴이 보이지 않는 컷은 장면 목적에 필요한 변경만 수행한다. S08에는 새 관광객의 흐린 오버더숄더 가장자리만 반영한다.

프레임별 동작, 카메라 높이, 개찰구 G3 위치, 실패·성공 표시, 심판 정체성과 TOSS 카드 노출 타이밍은 기존 스토리보드에서 바꾸지 않는다.

## 6. 생성·승격 순서

1. 제공된 Photo 1을 기반으로 새 관광객 캐릭터 락을 생성한다.
2. 빈 A04 우측 측면 통로 앵커를 생성한다.
3. A02와 A03의 관광객을 새 락으로 교체한다.
4. S02, S03, S04, S07, S09, S10, S13의 관광객 정체성을 교체한다.
5. A04를 기준으로 S06과 S08을 새 구도로 생성한다.
6. S12를 오른손 태그 구도로 생성한다.
7. 원본 생성 결과를 `frames/raw/`에 승격하고, 준비 스크립트로 `frames/final/`과 콘택트시트를 다시 만든다.
8. 프롬프트 팩, 연속성 바이블, 영상 프롬프트, QA 리포트와 매니페스트를 갱신한다.

기존 프레임은 Git 이력으로 보존하며, 최종 승인된 새 결과만 기존 S번호 경로에 반영한다.

## 7. 검수 기준

- 새 관광객 얼굴·머리·의상·가방·캐리어가 모든 등장 컷에서 동일하다.
- S06과 S08은 동일한 A04 우측 통로이며 개찰구 정면 배경이 없다.
- S06은 관광객 오버더숄더, S08은 동일 축의 접근 강화 컷이다.
- S12는 심판 화면 오른쪽, 카드가 든 오른손, 시계가 보이는 내려간 왼팔의 세 조건을 동시에 만족한다.
- S01–S09에는 TOSS 카드가 나타나지 않으며 S10부터 제품이 등장한다.
- 최종 13컷은 모두 1080×1920 RGB이고 콘택트시트 순서는 S01–S13이다.
- 이미지 생성 단계에는 자막과 광고 카피를 넣지 않는다.
