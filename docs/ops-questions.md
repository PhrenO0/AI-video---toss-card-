# 운영진·포리크루봇 문의 사항

토스 홍보 가이드가 "모르는 내용은 추측하지 말고 운영진이나 포리크루봇에 확인해 주세요"라고
명시했다. 아래는 **콘텐츠 제작이 실제로 막혀 있는 항목만** 추린 것이다.

답변을 받으면 [`content-workflow.md`](./content-workflow.md) §7의 표와
[`x-post-drafts.md`](./x-post-drafts.md)의 `[확인]` 표시를 함께 갱신할 것.

---

## 그대로 복사해 보낼 수 있는 메시지

```
안녕하세요, 9팀 TOSSTO입니다.
일본인 관광객 대상 콘텐츠를 제작 중인데, 가이드에 없어서 확인이 필요한 항목이 있습니다.
추측으로 쓰면 안 되는 내용이라 문의드립니다.

[1] 실물 카드 수령
Visitor 카드 실물은 어디서 어떻게 받나요? (공항 / 편의점 / 배송 / 앱에서 신청 후 수령)
"인천공항 도착 후 30분" 안내 콘텐츠를 만들고 있는데, 발급을 여행 동선 어디에
넣어야 할지가 이 답변에 달려 있습니다.

[2] 일본인 이용자의 충전 경로
가이드의 해외간편결제 충전수단이 홍콩·태국·말레이시아·필리핀·인도네시아로 안내되어 있는데
일본 결제수단은 목록에 없습니다. 계좌이체는 한국 계좌가 필요해 관광객에게는
해당이 없을 것 같습니다.
일본인 관광객은 편의점 현금 충전이 유일한 경로가 맞을까요?
일본 간편결제 추가 계획이 있다면 시점도 알려주시면 콘텐츠 일정에 반영하겠습니다.

[3] 편의점 현금 충전 조건
최소·최대 충전 금액과 수수료가 어떻게 되나요?
가이드에 "최신 앱 안내 기준"으로만 되어 있어 콘텐츠에 숫자를 쓰지 못하고 있습니다.

[4] "첫 Visitor 카드 무료"의 조건
수량이나 기간이 한정된 프로모션인가요, 상시 혜택인가요?
기간 한정을 상시처럼 표현하면 가이드 위반이라 확인이 필요합니다.

[5] 현재 진행 중인 프로모션
캐시백·제휴 혜택이 진행 중이라면 가이드 7번의 8개 항목을 알려주세요.
(진행 기간 / 대상 사용자 / 대상 매장 / 혜택률 / 최대 한도 / 지급 시점 /
 예산 소진 시 조기 종료 여부 / 제외 조건)

[6] 앱 일본어 지원
Visitor 서비스 가입 화면과 앱 UI가 일본어를 지원하나요?
지원한다면 화면 캡처 한 장이 일본인 타깃에게 강력한 소구가 됩니다.

[7] 앱 화면 캡처의 공개 범위
가입·발급·잔액 화면 캡처를 SNS에 게시해도 되나요?
마스킹 기준(계좌번호·실명·잔액 등)이 정해져 있다면 알려주세요.
제작 중인 콘텐츠의 절반이 앱 캡처를 사용할 예정이라 기준이 필요합니다.

[8] 디스클레이머 표기 형식
일본은 경품표시법상 광고에 #PR 표기가 의무입니다.
운영진이 지정한 표기 문구나 프로필 문구 형식이 있으면 그대로 따르겠습니다.
없다면 저희는 아래 형식으로 통일하려고 합니다.
 · 포스트 해시태그에 #PR
 · 프로필: 대외활동 계정임을 일본어로 명시
 · 이미지 하단: トス公式アカウントではありません（大学生クルー運営）

[9] 일반 이용자용 추천 인센티브 프로그램 여부
Visitor 카드에 이용자 본인이 다른 사람에게 추천코드를 공유하면 캐시백 등
혜택을 받는 구조가 있나요? (예: WOWPASS의 0.5% 환전 캐시백 추천코드,
크리에이트립의 팔로워 규모별 리워드형 앰버서더 프로그램)
있다면 저희 콘텐츠보다 그 구조 자체를 알리는 쪽이 전환에 훨씬 빠를 것 같아
우선순위를 조정하려고 합니다.

감사합니다.
```

## 답변 대기 중 진행 가능한 작업

| 산출물 | 상태 |
|---|---|
| X #3 (교통 통합) | ✅ 발행 가능 |
| X #5 (카드 거절) | ✅ 발행 가능 |
| X #8 (조건분기) | ✅ 발행 가능 |
| X #7 (공항 30분) | ⚠️ ④ 동사를 `用意する`로 두면 발행 가능 |
| 인스타 캐러셀 10장 | ⚠️ 7장의 제품 소개는 가이드 명시 범위 내 — 발행 가능 |
| 릴스 30초 | ✅ 발행 가능 |
| 촬영 세션 A·B | ✅ 지금 진행 가능 |
| X #10 (충전) | ⛔ [2][3] 답변 전 금지 |
| 프로모션 콘텐츠 | ⛔ [5] 답변 전 금지 |
| 앱 캡처가 들어가는 이미지 | ⛔ [7] 답변 전 보류 |

**[7] 앱 캡처 공개 범위가 가장 먼저 필요하다.** 초안 절반의 이미지 계획이 여기에 걸려 있고,
막히면 카드 실물·현장 촬영 중심으로 이미지 계획을 다시 짜야 한다.

**[9]는 답에 따라 전략 자체가 바뀐다.** 이용자 추천 인센티브가 있다면, 지금 짜둔
"정보 → 신뢰 → 제품" 발행 순서보다 그 프로그램을 알리는 콘텐츠를 앞으로 당겨야 한다.
WOWPASS·크리에이트립 둘 다 이 구조로 자발적 확산을 만들고 있어 경쟁 우위가 크다.
