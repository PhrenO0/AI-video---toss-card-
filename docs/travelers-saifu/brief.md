# Toss for Travelers 릴스「財布」篇 — 브리프

작성일: 2026-08-03
상태: 프롬프트 팩 작성 완료 · 생성 전 사용자 리뷰 대기

## 1. 개요

한국을 여행하는 **일본인 여성 관광객**을 통해 **Toss for Travelers(Visitor 서비스)**를 홍보하는
세로형(9:16) 릴스. 약 30초, 11컷. 토스 Foreigner Bridge Crew 2기 공모전 출품 대비.

**핵심 메시지 (단 하나):**

> 여행 지갑, 토스 카드 한 장으로.

지폐·동전·교통카드·여러 장의 카드로 빵빵한 지갑이 **Visitor 카드 한 장으로 정리된다**는 것을
말이 아니라 **같은 구도의 플랫레이 두 컷(S03 → S06)의 대비**로 보여준다.

## 2. 이번 산출물의 범위

- 산출물은 **프롬프트 문서뿐**이다. 이미지·영상 생성은 하지 않는다.
- 오디오 제작, 자막 번인, 어셈블리, 최종 렌더는 **이후 별도 단계**.
- 프롬프트는 **도구 비의존적**으로 작성한다 (GPT Image·Higgsfield 등 어디서든 사용 가능).

## 3. 단일 메시지와 가이드 정합성

홍보 가이드는 "한 콘텐츠에는 핵심 소구점 하나"를 요구한다. 본 기획의 메시지
**"여행 지갑, 카드 한 장으로"**는 가이드 추천 각도 중 다음에 정확히 해당한다.

> **Payment + transportation:** 결제와 대중교통을 카드 한 장으로 해결

따라서 개찰구 사용(S07)과 매장 결제(S08)를 함께 보여주는 것은 **메시지가 두 개인 것이 아니라,
하나의 메시지("한 장으로 다 된다")를 뒷받침하는 근거 두 개**다. 기능 나열형 콘텐츠가 아니다.

### 이 컨셉에서 특별히 주의할 점

| 위험 | 대응 |
|---|---|
| 지갑 속 교통카드·타사 카드가 식별되면 **타사 비방·비교**로 읽힐 수 있다 | 지갑 속 모든 카드는 **무브랜드**. 로고·문자·색상 조합까지 판독 불가하게 |
| "다른 건 버려라"로 읽히면 부정적 프레이밍 | **"한 장에 다 들어있다"**로 프레이밍. Visitor 카드는 티머니 기능을 *포함*한다 |
| "현금 필요 없음"은 과장 | 가이드 허용 범위인 **"많이 들고 다니지 않아도"**까지만 |
| 원화 노출 | 지폐·동전 자체는 통화이므로 노출 가능 (특정 금융사 표기 없어야 함) |

## 4. 제품 정보 (가이드 발췌 — 표현 정확성 기준)

Toss for Travelers - Visitor 서비스는 한국을 방문한 외국인을 위한 **선불 결제 서비스**다.

- **여권만으로 가입** — ARC(외국인등록증)·한국 은행 계좌 불필요
- **첫 Visitor 카드 무료**
- **한국의 카드결제 가능 매장에서 사용** — 특정 제휴 매장 한정이 아님
- **티머니 기능 포함** — 티머니를 지원하는 지하철·버스에서 사용
- 토스머니를 충전해 사용 (편의점 현금 충전, 계좌 이체, 일부 해외간편결제)

### 표현 금지/허용 대조

| 이렇게 | 이렇게 쓰지 않는다 |
|---|---|
| 여권만 있으면 가입할 수 있어요 | 가입하려면 ARC가 필요해요 |
| 첫 Visitor 카드는 무료예요 | 모든 발급·재발급이 항상 무료예요 |
| **선불카드**예요 | 신용카드·체크카드예요 |
| 카드결제 가능 매장에서 쓸 수 있어요 | 모든 온라인몰에서 쓸 수 있어요 |
| 티머니 기능으로 지하철·버스를 이용할 수 있어요 | 모든 교통수단에서 조건 없이 쓸 수 있어요 |
| 현금을 많이 들고 다니지 않아도 돼요 | 현금이 전혀 필요 없어요 |

**수치·과장 금지:** "1분 만에", "3초면" 등 검증되지 않은 시간·수치 금지.
"무조건", "100% 안전", "최고의", "다 됩니다" 금지.

**계열사 금지:** 토스뱅크·토스증권 등 계열사 서비스 언급 금지. 브랜드명은 **'토스' / toss**로만 표기.

## 5. 절대 준수 규칙 (위반 시 재작업)

| 항목 | 규칙 |
|---|---|
| **토스 로고** | **AI 생성 절대 금지.** 공식 `toss for travelers` 락업 파일만 후반 합성. 변형·색변경·타그래픽 결합 금지 |
| **토스 앱 화면** | **AI 생성 절대 금지.** 제공된 실제 앱 화면만 사용 (JPN 퍼널 스크린샷, 앱 녹화 mp4) |
| **디스클레이머** | 아래 문구를 **눈에 보이는 위치**에 반드시 삽입 |
| **카드 아트** | 생성 모델이 카드 로고·문자를 재그리면 **원본 PNG를 원근 맞춰 합성**으로 교체 |
| **사후 검수** | AI 생성물의 잘못된 명칭·환각 표현 육안 검수 필수 |

**디스클레이머 문구 (제공된 워터마크 이미지 사용, 좌/중앙/우 정렬 3종):**

> 토스 Foreigner Bridge Crew 대외활동으로 콘텐츠 제작을 지원받아 작성된 게시물이며,
> 최종 수상 시 상금 등 혜택을 받을 수 있습니다.

## 6. 고정 자산 (전 컷 일관성 기준)

### 인물 A — 일본인 여성 관광객 (주인공)

- 일본인 여성, 20대 중후반
- 다크브라운 세미롱 웨이브 헤어, 가벼운 시스루 뱅
- **아이보리 반소매 블라우스**, 밝은 베이지 미디 스커트
- **코랄/살몬 컬러 크로스백 스트랩** + 작은 크로스백 (가벼움의 시각적 증거)
- 자연스럽고 절제된 표정 — 과장된 만화적 리액션 금지
- S01~S06에서는 **큰 지갑**을 들고 있고, S09 이후에는 **지갑 없이 카드만**

### 인물 B — 동행 친구 (S10에만 등장)

- 같은 또래 여성, 담색 톤 여름 옷. 주인공보다 시각적 비중 낮게

### 로케이션

- 서울 지하철 역사 (개찰구·계단·플랫폼), 편의점/카페 계산대
- 오전~낮, 여름. 자연광 + 형광등 혼합. 청량하고 깨끗한 공간
- 특정 역명·브랜드 간판을 만들지 않는다

### 제품 — Toss Visitor 카드

- 원본: `assets/toss-card/pre-card-hologram-front (1).png` (블루 홀로그램 전면, **세로형**)
- 보조: `assets/toss-card/hand-pre-card-hologram.png` (손에 든 컷 참고)
- **카드가 등장하는 컷(S05·S06·S07·S08·S11)은 반드시 이 원본을 레퍼런스로 첨부**하고,
  프롬프트에 "로고·문자를 새로 그리지 말 것"을 명시한다
- 카드 최초 노출은 **S05**. S01~S04에는 등장하지 않는다

## 7. 컷 구성 요약 (11컷 / 약 30초)

| 컷 | 시간 | 내용 |
|---|---|---|
| S01 | 0–2s | **훅** 빵빵해서 안 닫히는 지갑, 동전이 쏟아진다 |
| S02 | 2–4s | 그녀 얼굴 — 난감한 작은 미소 |
| S03 | 4–7s | **오버헤드 플랫레이** 지폐·동전·무브랜드 카드들·영수증 |
| S04 | 7–9s | 폰을 꺼냄 — 화면은 **빈 플레이트**(실제 앱 화면 합성용) |
| S05 | 9–11s | 카드를 얼굴 옆에 들어 정면 — **히어로 제스처** |
| S06 | 11–13s | **플랫레이 재등장 — 잡동사니가 사라지고 카드 한 장만** ★핵심 컷 |
| S07 | 13–16s | 사용 ① 개찰구 태그 → 초록, 통과 |
| S08 | 16–19s | 사용 ② 편의점/카페 계산대 태그 |
| S09 | 19–22s | **모션 블러** 가벼워진 손으로 계단을 오른다 |
| S10 | 22–26s | 친구와 웃으며 지하철 탑승 |
| S11 | 26–30s | 카메라 보며 미소 + 카드 — **사인오프**(좌상단 로고·하단 워터마크 여백) |
