# 비트시트 — 컷별 연출 설계 (11컷 / 30초)

전제: [visual-grammar.md](./visual-grammar.md)의 10항목을 전 컷에 적용한다.
특히 **전경 보케 프레이밍**(좌우를 흐린 덩어리가 감싸는 구도)은 거의 모든 컷에 들어간다.

## 전체 리듬

| 구간 | 컷 | 역할 | 템포 |
|---|---|---|---|
| 문제 | S01–S03 | 지갑이 무겁다 | 차분하지만 답답하게 |
| 전환 | S04–S06 | 카드 한 장으로 정리 | S06에서 딱 떨어지는 해소 |
| 근거 | S07–S08 | 지하철·매장에서 실제로 쓴다 | 짧고 리드미컬하게 |
| 해소 | S09–S11 | 가벼워진 여행, 브랜드 | 열리고 밝아지며 마무리 |

**핵심 설계:** S03과 S06은 **완전히 동일한 탑다운 프레이밍·조명·배경**으로 촬영한다.
물건만 사라지는 대비로 메시지가 말 없이 완결된다. 이 두 컷의 일치가 영상 전체의 승부처다.

---

## S01 · 0.0–2.0s — 훅: 안 닫히는 지갑

| 항목 | 설계 |
|---|---|
| 카메라 | 손과 지갑 중심 미드클로즈. 렌즈 50mm, 높이 가슴 높이, 살짝 하이앵글로 지갑 내부가 보이게. 고정에 미세한 호흡감 |
| 전경 보케 | 좌우에 개찰구 하우징 또는 앞선 승객의 어깨를 크게 흐리게 |
| 조명 | 역사 창으로 들어오는 측면 자연광. 밝고 통풍감 있게 |
| 동작 | 지갑을 닫으려는데 두꺼워서 안 닫힌다 → 동전 몇 개가 손가락 사이로 떨어진다 |
| 표정 | (얼굴은 거의 안 보임 — 손 중심) |
| 오디오 | 역사 앰비언스(먼 웅성거림·안내방송), 동전 떨어지는 「チャリン」 |
| 자막 | 없음 |
| 의도 | **첫 2초에 "지갑이 문제"가 즉시 읽혀야 한다.** 가이드의 "첫 1~3초" 요건 |

## S02 · 2.0–4.0s — 난감한 얼굴

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 클로즈업. 85mm 압축, 눈높이. 아주 느린 푸시인 |
| 조명 | 부드러운 정면광 + 머리카락에 옅은 림라이트 |
| 동작 | 시선은 아래 지갑 쪽. 고개를 거의 들지 않는다 |
| 표정 | **난감한 작은 미소.** 눈썹의 미세한 움직임. 과장 금지 |
| 오디오 | 앰비언스 유지 + 작은 한숨 |
| 자막 | 일본어 소자막 시작 가능 |
| 의도 | 감정 이입 지점. 레퍼런스의 "자연스러운 표정 연기"를 가장 직접적으로 계승 |

## S03 · 4.0–7.0s — 오버헤드 플랫레이: 잡동사니

| 항목 | 설계 |
|---|---|
| 카메라 | **완전 수직 탑다운(90°)**. 24–35mm. 손이 프레임 안으로 들어와 물건을 헤집는다 |
| 배치 | 열린 지갑 중앙, 지폐 몇 장, **동전 무더기**, 카드 3~4장, 접힌 영수증, 작은 쿠폰 |
| 표면 | 밝은 무지 표면(카페 테이블·벤치). 밀키 화이트~연베이지 |
| 조명 | 위쪽 부드러운 확산광. 그림자 옅게 |
| ⚠️ 컴플라이언스 | **카드·교통카드는 전부 무브랜드.** 로고·문자·특징적 색조합 판독 불가 |
| ⚠️ 일치 | **S06과 프레이밍·높이·조명·표면을 동일하게** — 대비의 전제 |
| 오디오 | 동전 부딪히는 소리, 종이 스치는 소리 |
| 자막 | 나열감 있게 (예: 「現金、小銭、カード…」) |

## S04 · 7.0–9.0s — 폰을 꺼낸다 (빈 플레이트)

| 항목 | 설계 |
|---|---|
| 카메라 | 어깨 너머(OTS) 또는 손+폰 미드클로즈. 50mm |
| 화면 | **폰 화면은 균일한 밝은 플레이트**(연회색·화이트). 내용을 생성하지 않는다 |
| ⚠️ 컴플라이언스 | **앱 화면 AI 생성 금지.** 후반에 실제 앱 화면(JPN 퍼널 스크린샷·녹화 mp4) 합성 |
| 조명 | 화면 반사광이 얼굴에 옅게 |
| 오디오 | 앰비언스 + 아주 작은 터치음 |
| 자막 | 「パスポートだけで」 (여권만으로) |

## S05 · 9.0–11.0s — 히어로 제스처

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷. 50–85mm, 눈높이, 고정 |
| 프레이밍 | 얼굴 상단 1/3, **카드 중앙 1/3**. 얼굴과 카드가 한 프레임에 |
| 포즈 | 카드를 **세로로, 전면이 카메라를 향하게** 가슴~머리 높이로 든다 |
| 표정 | 밝지만 절제된 미소 |
| 조명 | 부드러운 정면광 + 역광 림라이트 |
| ⚠️ 제품 | **카드 원본 에셋 첨부 필수. 로고·문자 재그리기 금지** |
| 오디오 | 톤 전환 — 음악이 밝게 올라온다 |
| 자막 | 「これ一枚。」 (이 한 장으로) |
| 의도 | 카드 최초 노출. 레퍼런스의 제품 히어로 포즈를 그대로 계승 |

## S06 · 11.0–13.0s — ★핵심: 카드 한 장만 남는다

| 항목 | 설계 |
|---|---|
| 카메라 | **S03과 완전히 동일한 탑다운 프레이밍·높이·조명·표면** |
| 변화 | 잡동사니가 전부 사라지고 **중앙에 Visitor 카드 한 장만** |
| 연출 | S03과 매치컷. 손이 프레임을 한 번 쓸고 지나가면 정리된 상태가 된다 |
| 오디오 | 짧은 스와이프 + 맑은 단음. 그리고 **한 박자 정적** |
| 자막 | 「財布、軽くなった。」 (지갑이 가벼워졌다) |
| 의도 | **말 없이 메시지가 완결되는 컷.** 이 영상에서 가장 중요하다 |

## S07 · 13.0–16.0s — 사용 ①: 개찰구

| 항목 | 설계 |
|---|---|
| 카메라 | 리더기+손 클로즈업 → 통과하는 미드샷으로 컷. 35–50mm |
| 전경 보케 | 개찰구 하우징을 좌우에 크게 흐리게 |
| 동작 | 카드를 리더기에 태그 → 초록 표시 → 플랩 열림 → 걸어 통과 |
| ⚠️ 표시 | 개찰구 화면에 **문자 생성 금지.** 초록 화살표·체크 픽토그램만 |
| 오디오 | 「ピッ」 성공음, 플랩 기계음, 역사 앰비언스 |
| 자막 | 「地下鉄も」 + 하단 각주 「T-moneyが使える地下鉄・バスで」 |

## S08 · 16.0–19.0s — 사용 ②: 매장 결제

| 항목 | 설계 |
|---|---|
| 카메라 | 단말기+손 클로즈업 → 그녀의 밝은 표정 컷백. 50mm |
| 전경 보케 | 계산대 구조물·진열대를 좌우에 흐리게 |
| 장소 | 편의점 또는 카페 카운터. **브랜드 식별 불가하게** |
| 동작 | 카드를 단말기에 태그 → 결제 완료 |
| 오디오 | 결제 완료음, 매장 앰비언스 |
| 자막 | 「お店でも」 + 하단 각주 「カード決済ができる店舗で」 |

## S09 · 19.0–22.0s — 모션 블러: 가벼운 발걸음

| 항목 | 설계 |
|---|---|
| 카메라 | 뒤따라가는 느낌. 35mm, 로우~눈높이. **강한 자연 모션 블러** |
| 동작 | **작은 크로스백만** 메고 계단을 가볍게 오른다. **지갑은 없다** |
| 조명 | 계단 위에서 쏟아지는 역광. 하이라이트가 시원하게 날아간다 |
| 오디오 | 발걸음, 음악 고조 |
| 자막 | 없음 (호흡을 주는 구간) |
| 의도 | 리듬 전환 + "가벼워졌다"를 대사 없이 몸으로 증명 |

## S10 · 22.0–26.0s — 함께함

| 항목 | 설계 |
|---|---|
| 카메라 | 미드 투샷. 50–85mm. 전경에 손잡이·기둥 보케 |
| 동작 | 친구와 웃으며 지하철에 오른다 |
| 표정 | **눈을 내리깔며 부드럽게 웃는** 레퍼런스의 함께함 표정 |
| 조명 | 창밖 자연광이 부드럽게 들어온다 |
| 오디오 | 지하철 도착음, 짧은 웃음. (옵션) 짧은 자연 대사 「一緒に行こう」 |
| 자막 | 없음 또는 아주 작게 |

## S11 · 26.0–30.0s — 사인오프

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷. 카메라를 보며 은은한 미소, 카드를 손에. 50–85mm |
| 여백 | **좌상단(로고용), 하단 1/5(워터마크·카피용)** — 인물과 겹치지 않게 비운다 |
| 조명 | 밝은 역광, 배경 완전 보케 |
| 오디오 | 음악 마무리 + 잔향 |
| 후반 합성 | 좌상단 **공식 로고** / 메인 카피 / 한국어 소자막 / 각주 / **디스클레이머 워터마크** / CTA |
| ⚠️ 컴플라이언스 | 로고는 공식 파일만. 생성 프레임에는 어떤 문자도 넣지 않는다 |

## 전환 설계

| 전환 | 방식 |
|---|---|
| S01→S02 | 하드컷. 손에서 얼굴로 |
| S02→S03 | 하드컷. 시선이 아래로 향한 흐름을 탑다운으로 연결 |
| S03→S04 | 하드컷 |
| S04→S05 | 하드컷. 톤이 밝게 전환되는 지점 |
| **S05→S06** | **매치컷.** 카드를 든 손이 프레임 아래로 내려가며 탑다운으로 이어진다 |
| S06→S07 | 한 박자 정적 후 하드컷 |
| S07→S08 | 리드미컬한 하드컷 (태그 동작의 리듬을 맞춘다) |
| S08→S09 | 모션 블러로 스피드 전환 |
| S09→S10 | 하드컷 |
| S10→S11 | 부드러운 컷. 마지막은 정적으로 |

## 오디오 총괄

- **음악:** 밝고 가벼운 여름 톤. S01–S03은 절제, S05에서 리프트, S09에서 고조, S11에서 마무리
- **SFX:** 동전 「チャリン」(S01·S03) → 스와이프+단음(S06) → 「ピッ」(S07) → 결제음(S08)
- **대사:** 없음이 기본. 허용 범위는 짧은 감탄사와 S10의 「一緒に行こう」 정도.
  **스위치:** 대사를 완전히 배제하고 자막만으로 처리해도 설계는 그대로 성립한다
- **나레이션 없음**

## 자막 규칙

- 일본어 메인 + **한국어 소자막**(작게 병기)
- 하단 1/5 안전영역 안에 배치. 인물 얼굴·카드와 겹치지 않게
- 각주(티머니·결제 범위)는 더 작게, 해당 컷에만
- **생성 이미지에는 자막을 굽지 않는다.** 전부 후반 합성
- 폰트: Noto Sans JP / Noto Sans KR (또는 Yu Gothic)
