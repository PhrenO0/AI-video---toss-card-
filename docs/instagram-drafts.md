# Instagram 초안 — 캐러셀 · 릴스

[`content-workflow.md`](./content-workflow.md) §2-2의 10장 압축 매핑을 실제로 적용한 첫 편.
같은 주제를 **캐러셀 · 릴스 · X** 세 채널에 동시 발행해 2주차 보고서의
"플랫폼별 반응 차이" 근거를 만든다.

주제: **韓国での支払い、結局どうする？** (한국에서의 결제, 결국 어떻게 하지?)

선정 이유 — ① 운영진 확인 없이 지금 만들 수 있음 ② 하우투 장르는 저장률 18.3%로 최고
③ X에 실제로 올라온 「全部クレカでいける」 반론에 정면으로 답하는 소재

---

## A. 캐러셀 10장

### 저장률 3장치 배치

| 장치 | 위치 | 문장 |
|---|---|---|
| 저장하고 싶은 문장 | 9장 → 10장 | `保存しておくと、出発前に見返せます` |
| 공유하고 싶은 문장 | 4장 | `海外発行のカードは、お店によっては通らない` |
| 댓글이 달릴 질문 | 10장 | `韓国では何を使っていますか？` |

### 1장 — 후킹

```
韓国での支払い、
結局どれが正解？
```
**한국어** 한국에서의 결제, 결국 뭐가 정답?
**연결 문장** `先に結論から言います` (먼저 결론부터 말합니다)
**이미지** `제작` 딥 잉크 + 앰버 텍스트 카드. 헤드라인만, 여백 크게

---

### 2장 — 공감

```
出発前、いちばん迷うのがこれ

・現金はいくら持っていく？
・自分のカードは使える？
・交通カードは別で買う？
```
**한국어** 출발 전 가장 헷갈리는 게 이것 / 현금은 얼마나? / 내 카드는 쓸 수 있나? / 교통카드는 따로 사야 하나?
**연결 문장** `実際、こんな声をよく見ます` (실제로 이런 얘기를 자주 봅니다)
**이미지** `촬영` 캐리어와 여권이 놓인 출발 전 풍경

---

### 3장 — 공감

```
現地でよくある3つの困りごと

・お店でカードが弾かれた
・両替所を探して歩き回った
・交通カードの残高が足りない
```
**한국어** 현지에서 자주 있는 3가지 곤란 / 가게에서 카드가 거절됨 / 환전소를 찾아 헤맴 / 교통카드 잔액 부족
**연결 문장** `なぜ、こうなるのでしょうか` (왜 이렇게 될까요)
**이미지** `촬영` 계산대 앞 / 환전소 간판 / 개찰구 잔액부족 표시

---

### 4장 — 원인 ①

```
海外発行のカードは、
お店によっては通らない

個人経営のカフェや在来市場で
起きやすいと言われています
```
**한국어** 해외 발행 카드는 가게에 따라 안 될 수 있습니다 / 개인 카페나 재래시장에서 일어나기 쉽다고 합니다
**연결 문장** `もうひとつ、見落としがちな理由があります` (또 하나, 놓치기 쉬운 이유가 있습니다)
**이미지** `촬영` 재래시장 노점 · 개인 카페 계산대

> **공유하고 싶은 문장.** 이 한 장이 캐러셀 전체에서 가장 퍼진다. 단정하지 않고
> `〜と言われています`로 완충한 것에 주의 — 확인되지 않은 비율을 숫자로 쓰지 않는다.

---

### 5장 — 원인 ②

```
決済と交通が
別々だから

財布に2枚。
残高もそれぞれ管理することに
```
**한국어** 결제와 교통이 따로라서 / 지갑에 두 장, 잔액도 각각 관리하게 됩니다
**연결 문장** `では、どう選べばいいのか` (그럼 어떻게 고르면 될까요)
**이미지** `촬영` 지갑에 카드 두 장이 든 컷

---

### 6장 — 답 (조건분기)

```
選び方は、3つの軸だけ

▶︎荷物を増やしたくない
　→ 決済と交通が1枚のもの

▶︎弾かれるのが不安
　→ 韓国で発行するもの

▶︎最初にお金をかけたくない
　→ 発行料がかからないもの
```
**한국어** 고르는 기준은 세 축뿐 / 짐을 늘리고 싶지 않다 → 결제와 교통이 한 장 /
거절이 불안하다 → 한국에서 발행 / 처음에 돈을 들이고 싶지 않다 → 발급료 없음
**연결 문장** `この3つを満たすものがあります` (이 세 가지를 만족하는 게 있습니다)
**이미지** `제작` [`assets/design/02-choice-branches.svg`](../assets/design/02-choice-branches.svg) 재사용

---

### 7장 — 사례 (제품 첫 등장)

```
「Toss Visitorカード」

・パスポートだけで申し込めるプリペイドカード
・外国人登録証(ARC)も韓国の銀行口座も不要
・最初の1枚は無料
・T-money対応の地下鉄やバスでも使える
```
**한국어** 「Toss Visitor 카드」 / 여권만으로 신청 가능한 선불카드 / 외국인등록증(ARC)도 한국 은행 계좌도
불필요 / 첫 1장은 무료 / 티머니 지원 지하철·버스에서도 사용 가능
**연결 문장** `実際の1日で見てみます` (실제 하루로 보겠습니다)
**이미지** `애셋` `assets/toss-card/` 카드 실물 + `캡처` 앱 발급 화면

> **표현 규칙 4가지가 이 장에 전부 들어간다.** `プリペイドカード` · `最初の1枚` ·
> `T-money対応の` · (8장의) `カード払いができるお店`. 하나라도 빠지면 금지 표현이 된다.

---

### 8장 — 사용 장면

```
ソウルでの1日

朝　コンビニでコーヒー
昼　食堂でカルグクス
夕　地下鉄で移動
夜　カフェでデザート

カード払いができるお店なら、
この1枚でそのまま
```
**한국어** 서울에서의 하루 / 아침 편의점 커피 / 점심 식당 칼국수 / 저녁 지하철 이동 / 밤 카페 디저트 /
카드결제가 되는 가게라면 이 한 장으로 그대로
**연결 문장** `まとめます` (정리합니다)
**이미지** `촬영` 4컷 — 편의점 / 식당 / 개찰구 / 카페

---

### 9장 — 핵심 요약

```
覚えておくこと、3つ

① 海外発行カードは弾かれることがある
② 決済と交通は1枚にまとめられる
③ 最初の1枚は無料で始められる
```
**한국어** 기억할 것 세 가지 / ① 해외 발행 카드는 거절될 수 있다 ② 결제와 교통은 한 장으로 합칠 수 있다
③ 첫 1장은 무료로 시작할 수 있다
**연결 문장** `保存しておくと、出発前に見返せます` (저장해두면 출발 전에 다시 볼 수 있습니다)
**이미지** `제작` 3줄 요약 텍스트 카드

> **저장하고 싶은 문장.** 마지막이 아니라 9장 끝에 배치한 것이 의도적 —
> 10장까지 넘기게 만들면서 동시에 저장을 요구한다.

## B. 릴스 30초 (같은 내용 압축)

첫 2초에 결론, 자막은 1초차부터. 음소거 시청자 기준으로 설계.

| 초 | 화면 | 자막 (일본어) | 한국어 |
|---|---|---|---|
| 0–2 | 계산대 앞 손 클로즈업 | `韓国での支払い、結局どれ？` | 한국에서의 결제, 결국 뭐? |
| 2–5 | 캐리어·여권 | `出発前、ここでいちばん迷う` | 출발 전 여기서 가장 헷갈림 |
| 5–10 | 재래시장 노점 | `海外発行のカードは、お店によっては通らない` | 해외 발행 카드는 가게에 따라 안 됨 |
| 10–14 | 지갑 속 카드 2장 | `決済と交通が別々だと、財布に2枚` | 결제와 교통이 따로면 지갑에 두 장 |
| 14–20 | 조건분기 카드 | `選び方は3つ ─ 荷物・不安・初期費用` | 고르는 기준 셋 — 짐·불안·초기비용 |
| 20–26 | 카드 실물 + 앱 화면 | `パスポートだけで作れるプリペイドカード。最初の1枚は無料` | 여권만으로 만드는 선불카드. 첫 1장 무료 |
| 26–30 | 개찰구 태그 → 요약 카드 | `保存しておくと、出発前に役立ちます` | 저장해두면 출발 전에 도움됩니다 |

- **세로 9:16**, 상단 1/3은 인물·제품, 자막은 하단 안전영역 ([`storyboard.md`](./storyboard.md)와 동일 규칙)
- 나레이션 없이 자막만으로 성립해야 함
- 카드 실물은 `assets/toss-card/` 애셋 또는 실촬영. **AI 생성 금지**

## C. 3채널 동시 발행 계획

같은 주제를 세 채널에 맞게 변형해 같은 주에 발행한다.
**이것이 2주차 보고서 "플랫폼별 반응 차이" 칸의 근거가 된다.**

| 채널 | 형식 | 해시태그 | 핵심 지표 |
|---|---|---|---|
| Instagram | 캐러셀 10장 | 10~12개 | 저장 · 도달 |
| Instagram | 릴스 30초 | 10~12개 | 시청 유지율 · 저장 |
| X | 단일 포스트 #5 | 3~4개 | 리포스트 · 리플 · 북마크 |

**측정은 발행 후 48시간 시점**으로 통일해야 비교가 성립한다.
채널마다 측정 시점이 다르면 2주차 보고서에서 비교표를 못 만든다.
