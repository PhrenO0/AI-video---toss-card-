## 핵심 — 캐릭터 일관성

> **왕 주의: 프롬프트만으로는 커스텀 캐릭터가 정확히 안 나옴.
> 캐릭터 이미지를 직접 첨부해야 함.**

사용법: 캐릭터 이미지를 첨부하면서 `"이 캐릭터를 소흑 대신 써줘. [주제 또는 붙여넣을 글]"`

이후 동작:

- Higgsfield 또는 Gemini API가 연동되어 있으면 바로 이미지 생성, 아니면 프롬프트만 제공
- 프롬프트를 Higgsfield · Gemini · Google Flow 등 **image-to-image / reference 지원 툴**에 붙여넣으면
  캐릭터 이미지가 reference로 자동 적용
- **매 장마다 동일 reference 재사용 → 캐릭터 일관성 유지**
- Claude Code / Codex / Claude 채팅 모두 동일하게 작동

## 영상 제작 워크플로우

### STEP 1 — 스킬로 손그림 이미지 생성
- 주제 또는 글 입력 → 샷 리스트 확인 후 이미지 생성
- 캐릭터 있으면 이미지 첨부 + "이 캐릭터를 소흑 대신 써줘"
- **영상 한 편당 4~5장 권장, 16:9 가로형**

### STEP 2 — 스토리보드 생성
- 이미지 폴더 경로를 주고 "이 이미지들로 스토리보드 만들어줘. 00초 영상을 만들 거야" 요청
- 15초를 넘으면 스토리보드를 2개로 분할
- 필요 라이브러리: Python + Pillow (`pip install pillow`)
- Claude가 Python 스크립트를 생성해 이미지를 그리드로 합쳐 `storyboard.png` 출력
- 샷 순서, 비율(16:9 / 3:4), 레이블 유무를 요청으로 조정 가능

### STEP 3 — 영상 제작
- `storyboard.png`를 시댄스(Sydance)에 업로드
- "시댄스 영상 프롬프트 줘" → 샷별 시간·동작 포함 프롬프트 수령
- 나레이션 필요 시 "타임코드별 나레이션 스크립트도 같이 줘"
- 음성: ElevenLabs 또는 클로바 더빙 → 영상에 합성

## 우리 적용

**채택 — reference 첨부 원칙 (가장 중요)**

"프롬프트만으로는 정확히 안 나온다, 이미지를 첨부해야 한다"는 경고는
우리 프로젝트에 그대로 적용된다. 우리는 이미 [`../storyboard.md`](../storyboard.md)에서
캐릭터 시트·로케이션 마스터샷을 reference로 쓰고 있고, 여기에 **제품 애셋을 추가**한다.

`assets/toss-card/` 의 공식 카드 애셋 10장을 AI 생성 시 항상 reference로 첨부한다.
첨부 없이 만든 카드는 형태·로고가 실물과 달라져 **허위 표시**가 된다.

**조건부 채택 — 손그림 스타일**

"AI 티가 안 난다"는 강점이 있어 개념 설명 다이어그램·여행 동선 안내에는 유용하다.
다만 **제품 스펙·조건 설명과 카드 실물 표현에는 쓰지 않는다** —
손그림은 "대략적"으로 읽혀 금융 정보의 정확성 신뢰가 떨어진다.

**참고 — 스토리보드 그리드 자동화**

STEP 2의 "Python + Pillow로 이미지를 그리드 합성" 방식은
우리 릴스 제작에도 그대로 쓸 수 있다. 현재 `ai 스토리보드/` 에 낱장 PNG로 흩어져 있는 컷들을
한 장으로 합쳐두면 영상 툴 입력과 팀 리뷰가 동시에 편해진다.
