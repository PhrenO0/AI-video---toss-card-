# 비트시트 — 컷별 연출 설계 (12컷 / 30초)

전제: [visual-grammar.md](./visual-grammar.md)의 문법을 전 컷에 적용한다.
이 편의 척추는 **정면 고정 축**과 **전경에 걸린 친구들의 어깨**다.

## 촬영의 대원칙

**카메라는 버스정류장을 정면으로 보고 끝까지 그 축을 벗어나지 않는다.**
컷이 바뀔 때 앵글이 아니라 **사이즈만** 바뀐다. 카메라 위치는 이야기를 듣는 친구들의 자리이고,
그녀의 시선은 렌즈를 향한다. 전경 좌우에 친구들의 어깨가 흐리게 걸려 그 사이로 보는 구도가 된다.

## 전체 리듬 — 설명이 쌓이다가 버스에 끊긴다

| 구간 | 컷 | 역할 | 템포 |
|---|---|---|---|
| 설명 | S01–S06 | 귀여운 제스처로 카드를 설명한다 | 2~2.5초씩 (여유롭고 리드미컬) |
| **압박** | S07–S09 | 버스 접근 → 경고음 → 가려짐 | **2초씩 조여든다** |
| 착지 | S10 | 아무도 없다. 정적 | 2.5초 (길게 느껴진다) |
| 광고 | S11–S12 | 제품 인서트 → CTA | 4.5초 + 3초 |

**설계 의도:** S01–S06에서 설명이 즐겁게 쌓인다. S07에서 버스 소리가 들어오며 마감이 생기고,
S09에서 버스가 그녀를 가린다. **S10의 정적이 웃음의 착지점**이다. 이 정적을 충분히 주는 것이 중요하다.

## 긴장감 설계 (원작 「띵띵띵」의 대응)

**소리가 먼저 오고 그녀가 반응한다.** 이 순서가 지켜져야 관객이 그녀보다 먼저 눈치챈다.

| 시점 | 소리 | 시각 |
|---|---|---|
| S07 앞 | **버스 접근음이 뒤에서 서서히 커진다** | 아직 모르고 설명 중 |
| S07 | 에어브레이크 「プシュー」 | 뒤를 돌아본다 — 카운트다운 시작 |
| S08 | **문 닫힘 경고음 「ピピピピ…」** | 다급하게 마지막 설명 |
| S09 | 「プシュッ」 + 엔진 회전수 상승 | 버스가 프레임을 가로지른다 |
| S10 | **전부 빠지고 도심 앰비언스만** | 텅 빈 정류장 |

## S01 · 0.0–2.5s — 설명이 시작된다

| 항목 | 설계 |
|---|---|
| 카메라 | **정면 와이드.** 35mm, 눈높이. 고정 |
| 프레이밍 | 그녀가 정류장 앞 **화면 중앙**. 뒤로 정류장과 차도가 보인다 |
| 전경 보케 | **좌우에 친구들의 어깨**를 크게 흐리게 — 카메라가 그 사이로 본다 ★이 편의 기본 구도 |
| 조명 | 여름 정오 직후 자연광. 밝고 통풍감 있게 |
| 제스처 | ① 카메라를 향해 손을 흔들며 눈을 맞춘다. "얘들아, 들어봐" |
| 표정 | 밝고 신남. 뭔가 알려주고 싶어 못 참는 얼굴 |
| 오디오 | 도심 앰비언스 (차량·매미·먼 신호음) |
| 자막 | 없음 |
| 의도 | 장소·인물·관계를 2.5초에 세팅. **정면 축과 전경 어깨를 여기서 확립한다** |

## S02 · 2.5–5.0s — 카드를 들어 보인다 ★제품 최초 노출

| 항목 | 설계 |
|---|---|
| 카메라 | **정면 미드샷.** 50mm, 눈높이. 고정 (앵글 그대로, 사이즈만 조임) |
| 프레이밍 | 얼굴 상단 1/3, **카드 중앙 1/3.** 얼굴과 카드가 한 프레임에 |
| 제스처 | ② **카드를 얼굴 옆, 가슴~머리 높이로 들고 전면을 카메라로** |
| 표정 | "이거 봐!" 하는 밝은 자부심 |
| ⚠️ 제품 | **카드 원본 에셋 첨부 필수. 로고·문자 재그리기 금지** |
| 오디오 | 앰비언스. 음악이 살짝 올라온다 |
| 자막 | 없음 (카드가 말한다) |
| 의도 | 레퍼런스의 히어로 제스처를 그대로 계승 |

## S03 · 5.0–7.0s — 검지로 카드를 톡톡

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷 유지. 50mm |
| 제스처 | ③ 검지로 카드를 **톡톡 두드린다.** "이거야" |
| 표정 | 눈썹을 살짝 올리며 강조 |
| 오디오 | 앰비언스 + 음악 |
| 자막 | 없음 |

## S04 · 7.0–9.5s — 허공에 찍는 동작 ★시그니처 제스처

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷. 두 손이 프레임에 완전히 들어오게 살짝 넓게 |
| 제스처 | ④ **카드를 허공에 대고 손목을 툭 내려 찍는 시늉.** 「ピッ！」 입모양 |
| 표정 | 장난스럽고 뿌듯하게 |
| 오디오 | 앰비언스. 자막 SFX에 맞춰 후반에 「ピッ」 효과음을 얹어도 좋다 |
| 자막 | SFX 자막 「ピッ！」 (귀여운 손글씨풍) |
| 의도 | **이 광고의 시그니처.** 귀엽고, 한눈에 읽히고, 그 자체가 소구점이다. 「치즈—」의 대응 |

## S05 · 9.5–12.0s — 버스와 지하철을 가리킨다

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷 유지 |
| 제스처 | ⑤ 뒤쪽 차도를 가리킨다("버스도") → 손을 내려 아래를 가리킨다("지하철도") |
| 동작 원칙 | **한 번에 하나씩 명확하게.** 두 동작 사이에 짧은 멈춤 |
| 표정 | "둘 다 돼!" |
| 오디오 | 앰비언스 |
| 자막 | 없음 또는 아주 작게 |
| 의도 | 카피 「バスも、地下鉄も」와 제스처가 1:1로 대응한다 |

## S06 · 12.0–14.0s — 엄지 척 + 카드 디테일

| 항목 | 설계 |
|---|---|
| 카메라 | **정면 클로즈업.** 85mm. 축은 그대로, 사이즈만 조임 |
| 프레이밍 | 얼굴과 카드를 든 손이 가깝게. 카드 표면 디테일이 보인다 |
| 제스처 | ⑥ 엄지 척 + 고개를 살짝 기울인다. "좋지?" |
| 표정 | 부드럽고 자신 있게 |
| ⚠️ 제품 | 카드 원본 첨부. 이 컷에서 카드가 가장 크게 보인다 |
| 오디오 | 앰비언스. 음악이 가장 밝은 지점 |
| 자막 | 없음 |

## S07 · 14.0–16.0s — 버스가 온다

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷으로 되돌아온다 |
| 시각 | 뒤쪽 차도에 **버스가 들어와 정지한다** (흐리게, 형체만) |
| 제스처 | 말하다 멈추고 **뒤를 돌아본다** → 다시 카메라를 본다 |
| 표정 | "아, 벌써?" 하는 당황이 살짝 |
| 오디오 | **버스 접근음이 뒤에서 커진다** → 에어브레이크 「プシュー」 |
| 자막 | 없음 |
| 의도 | **소리가 먼저 오고 그녀가 반응한다.** 관객이 그녀보다 먼저 눈치챈다 |

## S08 · 16.0–18.0s — 다급하게 마지막 설명

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷 |
| 제스처 | ⑦ **손을 흔들며 뒷걸음질**로 버스 쪽으로 물러난다. 그러면서도 카드를 계속 들어 보인다 |
| 표정 | 다급하지만 여전히 밝게. "아 잠깐만—" |
| 시각 | **문 램프가 깜빡인다** (흐리게) |
| 오디오 | **문 닫힘 경고음 「ピピピピ…」** |
| 자막 | SFX 자막 「ピピピピ…」 |
| 의도 | 카운트다운. 컷이 짧아지기 시작한다 |

## S09 · 18.0–20.0s — 버스가 그녀를 가린다

| 항목 | 설계 |
|---|---|
| 카메라 | **정면 와이드.** S01과 같은 사이즈로 돌아온다. 고정 |
| 동작 | 버스가 **프레임을 가로질러** 들어오며 그녀를 완전히 가린다. 강한 수평 모션 블러 |
| ⚠️ 컴플라이언스 | **버스 노선번호·행선지·회사명 문자 생성 금지** |
| 오디오 | 「プシュッ」 + 엔진 회전수 상승 → 「ブロロ…」 |
| 자막 | 없음 |
| 의도 | 원작의 "기차가 지나가는 화면"의 대응. **화면을 덮는 순간이 전환점** |

## S10 · 20.0–22.5s — 아무도 없다 ★개그 착지

| 항목 | 설계 |
|---|---|
| 카메라 | **S01·S09와 완전히 같은 정면 와이드.** 고정 |
| 변화 | 버스가 지나간 뒤 **정류장에 아무도 없다.** 그녀가 사라졌다 |
| 전경 | 친구들의 어깨는 여전히 좌우에 걸려 있다 (그들은 남았다) |
| 오디오 | **모든 버스 소리가 빠지고 도심 앰비언스만.** 정적을 충분히 |
| 자막 | 「…」 정도 |
| 의도 | **웃음의 착지점.** S01과 같은 구도로 돌아와 "설명이 끝나지 않았다"가 완성된다. 서두르지 않는다 |

## S11 · 22.5–27.0s — 제품 인서트 (페이드아웃 후)

| 항목 | 설계 |
|---|---|
| 전환 | S10에서 **페이드아웃** → 제품 인서트로. 이 영상의 유일한 페이드 |
| 구성 | 흐린 실사 배경(정류장 보케) 위에 **카드 컷아웃 + 카피 + 각주** 플랫 오버레이 |
| 레이아웃 | 레퍼런스의 그래픽 인서트 카드 구조 계승. 카드 중앙, 카피 그 아래, 각주 하단 작게 |
| ⚠️ 제품 | 카드는 **원본 에셋을 그대로 합성**한다 (생성하지 않는다) |
| 오디오 | 음악이 밝게 들어온다 |
| 자막 | 선행 문구 + 메인 카피 + 각주 (→ [copy-deck.md](./copy-deck.md)) |
| 의도 | **선배가 못 끝낸 설명을 광고가 대신 마무리한다.** 인서트에 명분이 생기는 지점 |

## S12 · 27.0–30.0s — 친구들이 폰을 꺼낸다 (CTA)

| 항목 | 설계 |
|---|---|
| 카메라 | 미드 투샷. 85mm. 아주 느린 푸시인 |
| 반전 | **전경의 흐린 어깨로만 존재했던 친구들이 처음 얼굴을 드러낸다** |
| 동작 | 서로를 보고 끄덕이더니 **폰을 꺼내 함께 들여다본다.** 눈을 내리깔며 부드럽게 웃는다 |
| 화면 | **폰 화면은 빈 플레이트** → 실제 앱 화면 후반 합성 |
| 여백 | **좌상단(로고), 하단 1/5(워터마크·CTA)** 을 인물과 겹치지 않게 비운다 |
| 오디오 | 음악 마무리 + 잔향 |
| 후반 합성 | 좌상단 **공식 로고** / CTA / **디스클레이머 워터마크** / 실제 앱 화면 |
| 의도 | 가이드의 "다음 행동" 요건 충족. **듣던 사람이 움직였다**는 마무리 |

## 전환 설계

| 전환 | 방식 |
|---|---|
| S01→S06 | 전부 **하드컷.** 같은 정면 축에서 사이즈만 바뀐다 (와이드→미드→미드→미드→미드→클로즈업) |
| S06→S07 | **버스 접근음이 먼저 들리고 화면이 따라간다** (사운드 브리지) |
| S07→S08 | 하드컷. 경고음에 맞춰 |
| S08→S09 | 하드컷 |
| S09→S10 | 버스가 프레임을 빠져나간 직후 컷 — 소리가 한꺼번에 빠진다 |
| **S10→S11** | **페이드아웃 → 페이드인** (유일한 페이드. 개그와 광고를 분리한다) |
| S11→S12 | 부드러운 컷 |

## 오디오 총괄

- **음악:** 밝고 귀여운 여름 톤. S01에서 가볍게 시작 → S02에서 리프트 → **S06에서 가장 밝게** →
  S07–S09에서 긴장 → **S10에서 완전히 멈춤** → S11에서 다시 밝게
- **SFX 순서:** 앰비언스(S01–S06) → **버스 접근음+「プシュー」(S07)** →
  **「ピピピピ」(S08)** → 「プシュッ」+엔진(S09) → **정적(S10)**
- **대사:** 알아들을 수 있는 대사는 없다. 「ピッ！」 같은 짧은 의성어와 웅얼거림만 허용한다
- **나레이션 없음**

## 자막 규칙

- 일본어 메인 + **한국어 소자막**(작게 병기)
- **선배의 대사를 자막으로 옮기지 않는다.** 제스처가 말하게 한다
- SFX 자막(「ピッ！」「ピピピピ…」)은 **귀여운 손글씨풍**으로 — 원작의 톤
- 하단 1/5 안전영역 안에 배치. 인물 얼굴·카드와 겹치지 않게
- **생성 이미지에는 자막을 굽지 않는다.** 전부 후반 합성
- 폰트: Noto Sans JP / Noto Sans KR (SFX는 손글씨풍 별도 폰트)
