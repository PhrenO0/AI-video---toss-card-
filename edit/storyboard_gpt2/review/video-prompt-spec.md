# TOSS 일본인 관광객 광고 — 영상 프롬프트 명세

기준 이미지: `edit/storyboard_gpt2/frames/final/S01.png`–`S13.png`와 보조 제어 프레임 `S03A/S03B/S05A/S05B`.

## 공통 모션·공간 잠금

- 관광객은 `edit/generated/stills/tourist_lock_JP_v2.jpg`와 같은 인물(풀뱅, 어깨 길이 진한 갈색 머리, 흰 블라우스, 베이지 크로스백, 은색 캐리어)로 고정한다.
- 심판은 `edit/generated/stills/referee_lock_A.png`의 얼굴·체형·줄무늬 셔츠·검은 반바지·양말·풋살화·호루라기·왼손목 검은 시계를 유지한다.
- A05는 실제 한국 지하철의 구조 논리를 해석한 개찰구 홀이다. `타는 곳 / Tracks` 패널은 두 행거 봉과 천장 체결부가 보이는 물리적 표지판이다. A06은 G3에서 카메라를 약 90도 오른쪽으로 돌린 별도 복도 축이며, 개찰구와 Tracks 패널은 보이지 않는다.
- G3 리더기는 관광객 오른쪽에 있다. 실패 중 플랩은 닫혀 있고 TOSS 카드는 S10 전까지 보이지 않는다. 실패용 카드는 동일한 무광 회색 일반 카드이며 오른손에만 있다.
- 카메라는 작고 의도적인 돌리·펀치인·하드컷을 쓴다. 여행 릴스식 핸드헬드, 과한 롤링셔터, 랜덤 줌, 무의미한 포즈를 금지한다.
- 일본식 블루·골드 방사광은 S10–S11에만 제한한다. 지하철 배경 전체를 애니메이션으로 바꾸지 않는다.

- **Camera:** 35–50mm 고정 측면 와이드. 상단 **좌측 30–35%**는 조용한 최종 카피 안전영역이며, 실제 Tracks 표지판은 그 안전영역과 겹치지 않는 상단 오른쪽에 남을 수 있다.
- **Motion:** 관광객·캐리어 바퀴는 빈 통로의 같은 방향으로 굴러가며, 심판은 화면 오른쪽에서 한 번의 태그 동작을 마무리한다.
- **Gaze:** 관광객은 심판에게 감사의 눈길을, 심판은 리더와 통과 동작을 본다.
- **Transition:** 없음. 최종 카피를 후반 합성한다.
- **SFX:** 열린 플랩의 모터 잔향, 캐리어 바퀴, 짧은 브랜드 마무리음.
- **Overlay:** 15.0초부터 일본어 최종 카피를 상단 **좌측** 안전영역에만 합성. 이미지 생성 단계의 텍스트는 없음.
- **Negative motion:** 플랩 잔존·보행/캐리어 경로 방해·상단 좌측 카피 영역 침범·왼손 태그·올라간 왼손 시계·카드 복제·생성 글자 금지.
