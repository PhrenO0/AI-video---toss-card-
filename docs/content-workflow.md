## 1. 기획 원칙

### 1-1. 조회수가 아니라 체류시간

Ref 01의 핵심 주장이자 우리 1주차 실패와 정확히 맞물리는 지점.

> "첫 장만 클릭하게 만드는 것과 끝까지 읽게 만드는 것은 전혀 다른 이야기입니다.
> 조회수만 높은 콘텐츠와 저장·공유까지 이어지는 콘텐츠의 차이는 기획에서 시작됩니다."

1주차 실적은 조회 171 · 좋아요 3 · 전환 0이었다. 도달이 낮았던 것은 해시태그 부재 탓이지만,
**도달이 회복돼도 체류·저장 설계가 없으면 숫자만 커지고 전환은 그대로 0**이다.

- X: 리포스트 ×20 / 리플 ×13.5 / 북마크 ×10 / 좋아요 ×1 → 좋아요는 사실상 무의미
- Instagram: 하우투 장르 저장률 18.3%로 최고 → 우리 콘텐츠는 전부 하우투로

### 1-2. 후킹 조건 (그대로 채택)

- 너무 자극적이지 않을 것
- 뉴스 헤드라인처럼 작성
- 저장하고 싶은 정보처럼 보일 것
- **클릭베이트 금지**

토스 홍보 가이드의 "첫 1~3초 안에 관광객의 상황이나 혜택이 보여야 한다"와 충돌 없음.
오히려 클릭베이트 금지 조항은 가이드의 "확인 없이 단정하는 콘텐츠 금지"와 같은 방향이다.

### 1-3. 저장률 3장치

콘텐츠 한 편마다 아래 셋을 **의도적으로 배치**한다.

| 장치 | 목적 | 우리 적용 예 |
|---|---|---|
| 저장하고 싶은 문장 | 북마크 (×10) | `保存しておくと当日あわてません` |
| 공유하고 싶은 문장 | 리포스트 (×20) | 숫자·비교가 든 한 줄 |
| 댓글이 달릴 질문 | 리플 (×13.5) | `どこで弾かれましたか？` |

기존 초안은 "마지막 질문"만 넣고 있었다. **3종 세트로 확장**한다.

### 1-4. 콘텐츠 이중 운영 — 정보형과 프로모션형

X 운영을 `여행 정보 80% + 제품 20%` 하나의 공식으로 고정하지 않는다. 게시 목적에 따라 아래 두 축을 구분한다.

| 축 | 목적 | 제품 노출 | 대표 구조 |
|---|---|---|---|
| 정보·체험형 | 저장·프로필 방문·신뢰 형성 | 후반 20% 내외 | 실제 장소·문제 → 팁 → Toss 해결책 |
| 혜택·프로모션형 | 신청·링크 클릭·기간 내 행동 | 전면 노출 가능 | 대상 → 혜택 → 비용 → 기간 → 절차 → CTA |

혜택·프로모션형의 핵심 벤치마크는 **WOWPASS(ワウパス)日本公式 / @WOWPASS_JAPAN**이다.
2026-08-10 뷰티세트 게시물은 첫 문장에서 서울 방문 예정자를 호명하고, 상품 가치·배송비·신청 시점·대상 체류기간·숙소 배송이라는 의사결정 정보를 한 번에 제공했다.

> 참고 원문과 적용 분석: [`references/04-WOWPASS-X-프로모션.md`](./references/04-WOWPASS-X-프로모션.md)

#### 혜택·프로모션형 필수 정보 6개

1. **대상** — 누가 이용할 수 있는가
2. **혜택** — 무엇을 받거나 절약하는가
3. **실부담** — 무료인지, 발급료·배송비·충전금 등 비용이 있는가
4. **기간** — 신청·여행·수령 가능 기간
5. **절차** — 신청 → 선택 → 수령/사용 순서
6. **CTA** — 지금 무엇을 해야 하는가

하나라도 확인되지 않으면 빈칸을 추측으로 채우지 않는다. 특히 토스의 진행 중 프로모션은 운영진 확인 전 게시 금지다.

#### 슬라이드 역할

| 장 | 역할 | 원칙 |
|---|---|---|
| 1 | 키비주얼 | 혜택명·대상·핵심 숫자를 한 화면에 |
| 2 | 이용 혜택 | 정품/지원 범위/비용/기간 등 판단 정보 |
| 3 | 신청 방법 | STEP 1~3, 동사 중심 |
| 4 | 조건·주의 | 제외 대상, 준비물, 수령·사용 조건 |
| 선택 5 | 브랜드·제품 상세 | 광고 설명이 아니라 의사결정 보충 |

#### TOSSTO에 그대로 가져오지 않는 것

- `日本公式`(일본 공식), 인증 배지, 공식 고객지원 계정처럼 보이는 표현
- 확인되지 않은 한정 혜택·할인율·무료·수량·기간
- WOWPASS의 환전·엔화 충전 기능을 Toss에도 있는 것처럼 암시하는 비교
- WOWPASS의 주황색·W 심볼·카피·레이아웃을 식별 가능할 정도로 복제
- 캡션만 길고 이미지에서 조건을 확인할 수 없는 구성

TOSSTO는 프로필과 제품 언급 게시물에 **Bridge Crew 참가팀 운영 · PR · 비공식**임을 명시한다.

## 2. 20페이지 구조 → 우리 포맷 압축 매핑

Ref 01의 20페이지 구성은 인스타 캐러셀 전용이라 그대로 쓸 수 없다.
X는 단일 포스트가 기본이고, 신규 계정이 20장짜리를 만들 여력도 없다.
**흐름은 유지하고 길이만 압축**한다.

### 2-1. X 단일 포스트 (6행)

| 원본 구간 | 우리 행 | 역할 |
|---|---|---|
| 1p 후킹 | 1행 | 훅 (+ 이모지 1개, 줄 끝) |
| 2p 왜 이 이야기 | — | 생략 (공간 없음) |
| 3~5p 공감 상황 | 2행 | 공감 |
| 6~10p 문제 원인 | 3행 | 원인 |
| 11~15p 사례·예시 | 4행 | 답 (제품은 여기 한 번만) |
| 16~18p 인사이트 | — | 생략 |
| 19p 핵심 요약 | 5행 | 보너스 (✨로 마감) |
| 20p CTA | 6행 | 질문 → 리플 유도 |

마지막에는 **`#PR`을 필수로 두고, 주제 해시태그는 필요할 때만 1~2개** 추가한다. 여러 지역·품목 태그를 관성적으로 나열하지 않는다.

### 2-2. Instagram 캐러셀 (10장)

20장은 초기 계정에 과하다. 절반으로 압축하되 **연결 문장은 전 장에 유지**한다.

| 장 | 역할 |
|---|---|
| 1 | 후킹 |
| 2~3 | 공감 상황 |
| 4~5 | 문제 원인 |
| 6 | 답 |
| 7~8 | 실제 사례·사용 장면 |
| 9 | 핵심 요약 |
| 10 | CTA |

### 2-3. 연결 문장 (필수)

**모든 장 하단에 다음 장을 보게 만드는 한 줄을 넣는다.** Ref 01이 가장 강조하는 장치.

- ❌ `次のページへ` — 아무 정보가 없음
- ✅ `でも、ここで多くの人がつまずきます` — 다음 내용을 예고
- ✅ `理由は3つあります` — 개수를 예고

## 3. 발행 전 검수 체크리스트

Ref 01의 7개 항목과 토스 가이드의 6개 항목을 **하나로 병합**한 최종본.
발행 담당이 매번 확인한다.

### 기획
- [ ] 첫 장이 클릭하고 싶은가?
- [ ] 두 번째 장을 넘길 이유가 있는가?
- [ ] 중간에 이탈할 페이지가 있는가?
- [ ] 마지막까지 읽으면 얻어가는 정보가 있는가?
- [ ] 저장할 이유가 있는가? (저장 문장이 실제로 들어갔는가)
- [ ] 공유할 이유가 있는가?
- [ ] CTA가 자연스러운가? (억지스럽지 않은가)

### 정확성 — 토스 가이드
- [ ] 관광객에게 유용한 이유가 첫 부분에 드러나는가?
- [ ] 핵심 메시지가 **하나**로 명확한가?
- [ ] 금지 표현을 쓰지 않았는가? (§3-1)
- [ ] 명시한 조건이 최신 정보와 일치하는가?
- [ ] 다음에 무엇을 하면 되는지 알 수 있는가?
- [ ] **디스클레이머가 눈에 보이는 곳에 있는가?**

### 3-1. 절대 빼면 안 되는 4가지 표현

문장을 다듬다가 빠지는 순간 **금지 표현**이 된다.

| 필수 표현 | 빠지면 생기는 문제 |
|---|---|
| `プリペイドカード` (선불카드) 명시 | 신용·체크카드로 오인 |
| `最初の1枚` (첫 1장) 한정 | "모든 발급·재발급 항상 무료"가 되어 허위 |
| `カード払いができるお店` 조건 유지 | 현금만 받는 가게까지 포함되어 허위 |
| `T-money対応の` 한정 | "모든 교통수단 조건 없이"가 되어 허위 |

### 3-2. 일본인 타깃 최대 리스크 — 충전수단

토스 가이드의 해외간편결제 충전수단은 **홍콩·태국·말레이시아·필리핀·인도네시아**뿐이며
**일본 결제수단이 없다.** 계좌이체는 한국 계좌가 필요해 관광객에게 해당 없음.

→ 일본인의 현실적 충전 경로는 **편의점 현금 충전**이고, 이는 **원화 현금이 필요**하다는 뜻이다.

**`両替不要` / `両替所に行かなくていい` 류 소구는 절대 금지.**
경쟁 제품 WOWPASS는 키오스크에 엔화를 넣으면 원화로 충전되는 환전 겸용 구조다.
**환전 축에서 싸우면 진다.** 우리 축은 `무료 + 여권만 + 카드 한 장`.

### 3-3. 2주차 공지로 추가된 표현 규칙

어드바이저 1주차 공통 피드백(2026-08-12)에서 새로 확정된 항목. §3-1과 같은 강도로 지킨다.

**① 온라인 결제 — 토스페이와 구분할 것**

| 사실 | 표현 |
|---|---|
| 카드를 결제수단으로 **'등록'해서** 온라인·앱 결제 → **불가능** | ❌ `オンライン決済にも登録できます` 류 금지 |
| 비회원 간편결제 **'토스페이'가 있는 곳**에서만 온라인 결제 가능 | ✅ `トスペイが使えるオンライン加盟店で決済できます` |

기존 초안에는 "모든 온라인몰에서 사용 가능"류 표현이 없어 수정 대상은 없다.
앞으로 온라인 결제를 소재로 쓸 때 이 구분을 반드시 지킨다.

**② 외국인등록증(ARC)을 언급하지 않는다 — 관광객 대상 한정**

관광객은 한국 내 신분증인 외국인등록증이 뭔지 모른다. **`パスポートだけで登録できます`면 충분하다.**
ARC 언급은 **단기 유학생 대상 콘텐츠에서 필요할 때만** 쓴다.

> 이 규칙으로 X 초안 #2와 인스타 캐러셀 7장에서 `外国人登録証(ARC)`를 제거했다.
> `韓国の銀行口座` 언급은 그대로 둔다 — 관광객도 이해하는 개념이다.

| 실제 서울 장소 사진 | ⚠️ 실촬영 권장 — 일본인 이용자는 서울 지리에 밝은 사람이 많음 |

## 5. 레이아웃 먼저, 텍스트 나중

Ref 03의 한 문장이 이번 채택에서 가장 실용적이다.

> "레이아웃 먼저 정하고, 텍스트 얹기.
> 이미지 먼저 만들고 글자를 얹으면 무조건 스티커 티가 난다.
> 프롬프트에 **'왼쪽 위 1/3은 헤드라인 자리로 비워줘'** 한 줄이면
> 이미지가 글자 자리를 만들며 태어난다."

### 5-1. 적용 규칙

- AI 이미지 생성 프롬프트에 **글자 자리를 먼저 지정**한다
  - 예: `leave the top-left third as empty negative space for a headline`
- 카드 디자인은 **1080×1080 그리드에 텍스트 블록을 먼저 배치**한 뒤 배경을 채운다
  ([`design-system.md`](./design-system.md)의 SVG 5종이 이미 이 방식)
- 세로 영상은 상단 1/3을 인물·제품, 하단 안전영역을 자막에 배정 (storyboard.md와 동일)

### 5-2. 손그림 스타일 — 보조 포맷으로만

Ref 02의 손그림 다이어그램(흰 배경 + 검정 선화 + 빨강/주황/파랑 손글씨)은
"AI 티가 안 난다"는 강점이 있어 유용하다. 다만 **적용 범위를 제한**한다.

| 용도 | 판정 |
|---|---|
| 개념 설명 다이어그램 (결제 흐름, 비교 구조) | ✅ 사용 |
| 여행 동선·지도 안내 | ✅ 사용 |
| 제품 스펙·조건 설명 | ❌ 실캡처 유지 — 손그림은 "대략적"으로 읽혀 정확성 신뢰가 떨어짐 |
| 카드 실물 표현 | ❌ 공식 애셋만 |

## 6. 발행 운영

| 항목 | 기준 |
|---|---|
| 빈도 | 주 3회, 하루 1개 (하루에 몰면 X 연투 감점) |
| 시각 | JST 21~23시 (한일 시차 없음, 한국 시간 그대로) |
| 초동 | 발행 후 60분 팀 대기. **이모지만 다는 리플은 감점** — 실제 질문·보충 정보로 |
| 기록 지표 | 임프레션 / 리포스트 / 리플 / 북마크 / 프로필 클릭 |
| 로그 표기 | 보고서 플랫폼 드롭다운에 X가 없음 → **'기타'** 선택 + 주제 칸 앞에 `[X]` |
| 측정 루틴 | 매주 수요일 22:50 알람, 담당자 1명 고정. 발행 즉시 로그 행 선생성 |

### 6-1. 디스클레이머

일본은 2023년 10월부터 경품표시법상 광고에 `#PR` 표기가 **법적 의무**이며 책임은 사업자 측에 있다.
토스 가이드 체크리스트의 "디스클레이머가 눈에 보이는 곳에"와 같은 항목이다.

- 제품·추천코드를 언급하는 모든 포스트에 `#PR`
- 프로필에 대외활동 계정임을 일본어로 명시
- **이미지 안에도 디스클레이머 줄을 넣는다** — 캡션은 접히지만 이미지는 안 접힌다

### 6-2. 전환 링크

팀 공식 추천 링크는 아래 하나뿐이다. **다른 링크를 임의로 만들지 않는다.**

```
https://toss.im/?pid=referral_partners_online_FORICREW09
```

배치는 플랫폼마다 다르다.

| 플랫폼 | 배치 |
|---|---|
| Instagram (피드·릴스 캡션) | **캡션 안 링크는 클릭되지 않는다.** 캡션에는 `プロフィールのリンクから` 유도 문구만 넣고, 실제 URL은 프로필 편집 → 웹사이트 칸에 등록 |
| X | 본문에 외부 링크가 있으면 도달이 눌리는 경향 → **본문에는 링크 없이 발행, 발행 직후 첫 리플로 링크를 단다** |

## 8. 2주차 공지 반영 — 기획·운영 지침

출처: 어드바이저 1주차 공통 피드백 & 필수 안내 (2026-08-12)

### 8-1. 기능이 아니라 '상황'에서 출발한다

> 관광객은 토스 카드의 기능이 궁금해서 우리를 찾는 게 아니다.
> 본인 여행에 도움 될 걸 찾다가 우연히 만나는 것이다.
> 첫 장부터 기능만 설명하면 광고로 인지하고 바로 이탈한다.

콘텐츠를 만들기 전에 **어떤 관광객을, 어떤 상황에서 노릴지**부터 정하고,
그 상황 안에 토스를 자연스럽게 녹인다.

우리가 이미 맞춰둔 부분 — 발행 순서를 `정보 → 신뢰 → 제품`으로 짠 것,
X #7(공항 30분)에서 제품을 5단계 중 한 줄로만 넣은 것, #8(조건분기)에서
제품을 마지막 한 줄에만 놓은 것이 전부 이 원칙과 같은 방향이다.

### 8-2. 저장·공유가 실제 전환 신호다

조회수보다 **저장·공유**를 본다. 여행객은 미리 저장해뒀다가 필요한 순간에 꺼내본다.

콘텐츠 안에 **저장을 유도하는 한 줄**을 넣는다.
`保存しておくと当日あわてません` / `保存しておくと、出発前に見返せます` 형태.
§1-3의 저장률 3장치와 같은 요구다.

### 8-3. 채널을 줄이지 말고 많이 발행한다

> 정교한 한 편에 오래 매달리기보다, 다양한 채널에 많이 발행하며 데이터를 쌓는 게 훨씬 중요하다.
> 발행이 빠를수록 다음 콘텐츠를 개선할 시간이 생긴다.

채널 수를 줄이지 않는다. 각 채널의 색을 살리면서 폭넓게 시도한다.
→ **X·Instagram 동시 발행 계획**([`instagram-drafts.md`](./instagram-drafts.md) C절)을 그대로 밀고,
막힌 초안을 기다리며 발행을 멈추지 않는다.

### 8-4. 성과 분석을 반드시 채운다

데이터가 적더라도 **그 하나의 숫자라도 '왜 이 정도 나왔을까'를 스스로 해석**한다.
콘텐츠 로그의 조회·저장·공유 수치를 빠짐없이 기록한다.
보고서에 고민의 흔적이 많을수록 받을 수 있는 피드백도 늘어난다.

### 8-5. 부정적 반응·잘못된 정보에 직접 대응하지 않는다

댓글에 토스에 대한 부정적 동향이나 잘못된 정보로 호도하는 경우가 생길 수 있다.
**직접 대응하지 말고 어드바이저에게 공유**한다. 팩트체크 후 대응 방향을 받는다.

> DM 자동응답·FAQ를 운영할 때도 같다. 논쟁성 질문은 자동응답으로 처리하지 않는다.

### 8-6. 디스클레이머를 잘 보이게

프로필 사진에 토스 공식 로고를 쓴다면 프로필 소개에
**"토스 포리너 브릿지 크루 대외활동용 계정입니다"**를 반드시 넣는다.
공통 디스클레이머는 잘 보이는 곳에 넣는다 — 숨은그림 찾기처럼 넣지 않는다.
§6-1과 같은 요구이며, 이미지 안에 넣는 우리 방식이 이 조건을 만족한다.

### 8-7. 확인 대기 — 프로모션 가이드 갱신

포리크루 가이드에 **올리브영 포함 프로모션 내용이 새로 추가**되었다.
§7의 [5]번(프로모션 조건 8개 항목)과 직결된다.
**갱신된 가이드를 받기 전까지 프로모션 콘텐츠는 만들지 않는다.**
