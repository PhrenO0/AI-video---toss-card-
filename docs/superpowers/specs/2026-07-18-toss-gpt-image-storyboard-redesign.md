## 1. 목적과 완성 조건

한국 지하철 개찰구에서 교통카드 사용에 실패한 일본인 여성 관광객에게 축구 심판이 나타나 TOSS 선불카드를 선언하고 직접 게이트를 열어 주는 9:16 실사 광고 스토리보드를 만든다.

완성 조건은 다음과 같다.

- 새 스토리보드 이미지는 Higgsfield가 아닌 Codex 내장 GPT Image 도구로 생성한다.
- 최종 스토리보드는 13개의 개별 세로형 프레임으로 구성한다.
- 예상 영상 길이는 약 18초이며, 빠른 컷과 의도적인 정적을 교차시킨다.
- 대사와 말풍선은 사용하지 않는다. `삐빅`, 호루라기, `띠링`은 후반 음향으로 처리한다.
- 실패 장면에서는 TOSS 카드가 보이지 않는다.
- 제품 공개 장면부터는 실제 TOSS 카드 원본의 비율·색·로고·칩 방향을 보존한다.
- 개찰구 물리법칙, 인물 동선, 시선 방향이 컷 사이에서 모순되지 않아야 한다.
- 생성 이미지에는 자막을 굽지 않는다. 엔딩 카피가 들어갈 여백만 설계한다.

## 3. 공간 좌표와 물리법칙

공간은 서울의 현대적인 지하철역 개찰구로 설정하되, 특정 역명이나 불필요한 브랜드 문자는 만들지 않는다.

- 카메라는 기본적으로 비결제 구역에서 개찰구를 바라본다.
- 중앙의 목표 게이트를 `G3`로 정한다.
- 관광객은 화면 왼쪽 밖에서 들어와 `G3` 입구에 선다.
- 리더기는 관광객의 오른손 쪽, 화면 오른쪽 게이트 하우징 상단에 있다.
- 실패 시 관광객의 발은 닫힌 플랩 앞에 있고, 캐리어는 몸의 뒤쪽 왼편에 남는다.
- 관광객은 실패 상태에서 플랩을 통과하거나 결제 구역 안에 서 있지 않는다.
- 심판은 관광객 오른쪽의 인접 통로 `G4`에 나타난다.
- 심판은 `G4`를 따라 카메라 쪽으로 다가온 뒤 관광객 프레임의 오른쪽에서 왼쪽으로 진입한다.
- 마지막에는 심판이 관광객 오른편에서 `G3` 리더기에 TOSS 카드를 태그한다.
- 성공 후에만 플랩이 열리고 관광객과 캐리어가 함께 통과한다.

이 좌표와 좌우 방향은 모든 프롬프트에 반복하여 장면별 공간 드리프트를 방지한다.

## 5. 리듬과 화면 애니메이션

영상의 강약은 네 구간으로 나눈다.

1. **현실적 도입, 0.0–4.3초:** 안정된 카메라와 실제 지하철 조명. 실패 직후만 짧게 정지한다.
2. **부조리한 개입, 4.3–9.4초:** 휘슬 스매시컷, 심판 공개, 낮은 카메라와 점진적 펀치인으로 긴장을 올린다.
3. **제품 선언, 9.4–13.2초:** 방사광·프레임 스텝·최고점 정지·빠른 하강을 연속 사용한다. 가장 광고적인 구간이다.
4. **해결과 브랜드 호흡, 13.2–18.0초:** 게이트 성공 후 움직임과 음향을 가라앉히고 카피가 읽힐 시간을 만든다.

전환 규칙은 다음과 같다.

- S01→S02: 동일한 고정 카메라로 연결한다.
- S02→S03: 관광객의 오른팔이 뻗는 순간 하이앵글로 하드컷한다.
- S04→S05: 실패음의 리듬을 휘슬로 이어 사운드 브리지를 만든다.
- S05→S06: 호루라기 클로즈업에서 심판 위치를 밝히는 와이드로 스매시컷한다.
- S08→S09: 심판의 몸이 렌즈 가까이 도달한 순간 인물 와이프를 만든다.
- S10→S11: 카드의 상승 방향을 유지하는 매치컷을 사용한다.
- S11→S12: 빠른 팔 하강을 리더기 클로즈업으로 이어 붙인다.
- S12→S13: 성공음 끝에 측면 와이드로 전환하고 플랩 개방과 관광객 통과를 보여 준다.

## 6. 시각 스타일

- 9:16 세로형 프레임, 현실적인 일본 프리미엄 TV 광고 질감
- 차갑고 깨끗한 서울 지하철 형광등과 은은한 청록색 반사광
- 실제 금속·유리·고무 표면의 질감, 과도하게 매끈한 AI 렌더 느낌 금지
- 초반 28–35mm 관찰형 렌즈, 심판 등장 후 50–70mm 압축과 로우앵글 사용
- 얕은 심도는 인물 반응과 제품 공개에만 제한적으로 사용
- 배경 승객은 최소화하고 얼굴이나 문자가 주의를 빼앗지 않게 한다.
- 일본식 효과는 S10–S11의 방사광·짧은 스텝 모션에만 사용한다.
- 애니메이션풍 배경 교체나 만화 말풍선은 사용하지 않는다.

## 8. 이미지 제작 구조

GPT Image 생성은 앵커 우선 방식으로 진행한다.

1. `A01_gate_master`: G3·G4·리더기·플랩 방향이 명확한 빈 개찰구 마스터
2. `A02_tourist_gate_master`: 관광객이 G3 결제선 앞에 선 위치 마스터
3. `A03_referee_gate_master`: 동일 공간에서 심판이 G4에 선 위치 마스터
4. 세 앵커와 캐릭터 기준 이미지를 참조해 S01–S13을 각각 별도 생성
5. 카드 모서리가 처음 보이는 S10부터 S13까지 실제 카드 PNG를 적용하고 원근·가림·빛 반사를 맞춤
6. 개별 프레임 검수 후 13컷 콘택트시트와 영상 프롬프트용 컷 명세를 작성

하나의 다중 패널 이미지를 한 번에 생성하지 않는다. 각 컷을 개별 생성해야 해상도, 표정, 손, 카드, 개찰구 구조를 독립적으로 수정할 수 있다.

## 9. 실패 처리와 검수 기준

한 프레임이 실패하면 전체 세트를 다시 만들지 않고 해당 컷만 같은 앵커를 참조하여 재생성한다.

프레임별 필수 검수 항목:

- 관광객 얼굴·머리·의상·가방·캐리어 연속성
- 심판 얼굴·체형·유니폼·호루라기·시계 연속성
- 손가락 수, 팔 방향, 카드 그립과 접촉 위치
- G3·G4의 위치, 리더기 우측 배치, 플랩 전후 관계
- 실패 시 닫힌 플랩과 캐리어 위치
- 성공 후에만 열린 플랩
- TOSS 카드 공개 시점과 실제 제품 전면 정확성
- 무작위 역명, 왜곡된 안내문, 잘못된 로고, 워터마크 부재
- S04는 아래쪽 시선, S07은 화면 오른쪽 시선
- S09의 심판 이동 방향은 화면 오른쪽에서 왼쪽
- S13의 카피 안전영역 확보

최종 합격 기준은 무음으로 콘택트시트를 보아도 `장소 소개 → 실패 → 휘슬의 정체 → 심판 접근 → 카드 선언 → 성공 → 브랜드`가 순서대로 읽히는 것이다.

## 10. 범위

이번 단계의 제작 범위는 13개의 실사 스토리보드 프레임, 13컷 콘택트시트, 컷별 영상 프롬프트 명세다. 실제 영상 생성·음향 제작·자막 애니메이션·최종 편집은 스토리보드 승인 이후 별도 단계에서 수행한다.
