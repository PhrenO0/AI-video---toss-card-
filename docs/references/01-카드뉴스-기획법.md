# Ref 01 · 저장되는 카드뉴스 공식 프롬프트 공유

원문: `clear-decimal-c9d.notion.site/39e1a5043ab18007988efcc6da02bb7d`
주제: 조회수와 체류시간을 동시에 잡는 카드뉴스 기획법

---

## 핵심 논지

> 많은 사람들이 카드뉴스를 만들 때 가장 먼저 신경 쓰는 것은 첫 장입니다.
> 강한 후킹, 자극적인 제목, 궁금증을 유발하는 문장. 물론 중요합니다.
> **하지만 첫 장만 클릭하게 만드는 것과, 끝까지 읽게 만드는 것은 전혀 다른 이야기입니다.**
> 조회수만 높은 콘텐츠와 저장과 공유까지 이어지는 콘텐츠의 차이는 기획에서 시작됩니다.

## 사례 수치

저자가 제시한 실제 카드뉴스 1건의 성과:

| 지표 | 값 |
|---|---|
| 조회수 | 6.5만 |
| 저장 | 2,500 |
| 공유 | 1,300 |
| 프로필 방문 | 1,600+ |
| 광고비 | 0원 |

> 인스타그램 스폰서 광고(CPM 방식)로 6.5만 회의 유의미한 노출을 만들려면
> 대략 50만 원 ~ 100만 원 상당의 광고비를 태워야 하는 화력입니다.

저장 2,500 / 조회 6.5만 = **저장률 약 3.8%**.
프로필 방문 1,600 / 조회 6.5만 = **약 2.5%**.

> 결국 중요한 건 조회수가 아니라 사람들이 내 계정으로 들어오고,
> 내 서비스를 보고, 실제 문의와 매출로 이어지는 콘텐츠를 만드는 것

---

## 후킹 조건

첫 장 제목 작성 시 지켜야 할 4가지.

- 너무 자극적이지 않을 것
- 뉴스 헤드라인처럼 작성
- 저장하고 싶은 정보처럼 보일 것
- **클릭베이트 금지**

## 20페이지 구성

| 페이지 | 역할 |
|---|---|
| 1 | 후킹 |
| 2 | 왜 이 이야기를 해야 하는지 |
| 3~5 | 사람들이 공감하는 상황 |
| 6~10 | 문제의 원인 |
| 11~15 | 브랜드 사례 또는 실제 예시 |
| 16~18 | 디자인 관점 또는 인사이트 |
| 19 | 핵심 요약 |
| 20 | CTA |

각 페이지마다 **제목 / 들어갈 내용 / 다음 페이지를 넘기게 만드는 연결 문장**을 작성한다.

## 저장률을 높이는 3장치

카드뉴스 안에 아래 셋을 각각 배치한다.

1. 저장하고 싶은 문장
2. 공유하고 싶은 문장
3. 댓글이 달릴 질문

## CTA

억지스럽지 않은 CTA를 5가지 버전으로. 예시 경로: 댓글 · DM · 프로필 · PDF · 노션.

## 디자인 포인트

각 페이지마다 **들어갈 이미지 / 레이아웃 / 강조할 키워드 / 텍스트 비중**까지 지정한다.

## 검수 체크리스트

- [ ] 첫 장이 클릭하고 싶은가?
- [ ] 두 번째 장을 넘길 이유가 있는가?
- [ ] 중간에 이탈할 페이지가 있는가?
- [ ] 마지막까지 읽으면 얻어가는 정보가 있는가?
- [ ] 저장할 이유가 있는가?
- [ ] 공유할 이유가 있는가?
- [ ] CTA가 자연스러운가?

## 추가 지시사항 (원문)

- 카드뉴스는 20페이지 기준으로 작성
- **첫 장보다 2~19페이지의 체류시간을 가장 중요하게** 생각할 것
- 매 페이지마다 다음 페이지를 보게 만드는 연결 문장을 반드시 넣을 것
- 정보 전달보다 **스토리텔링을 우선**으로 구성
- 뉴스 기사처럼 객관적인 흐름과 브랜드 인사이트를 함께 담을 것

---

## 저자의 경고 (중요)

> 이 프롬프트는 기획을 빠르게 도와주는 도구입니다.
> **하지만 이 결과물을 그대로 복사해서 사용하는 것은 추천하지 않습니다.**
> 조회수가 높고 저장이 많이 되는 콘텐츠는 결국 '나만의 경험'이 들어가야 합니다.

들어가야 할 것: 직접 겪은 실패 / 실제 클라이언트 사례 / 작업하면서 느낀 점 /
수강생 피드백 / 실제 브랜드 분석 / 나만의 생각과 인사이트.

  (제도 변경, 신규 오픈, 실제로 결제해본 기록 — 일본에서는 만들 수 없는 콘텐츠)
