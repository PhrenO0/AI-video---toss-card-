# Toss for Travelers 릴스「バス停」篇 — 브리프

작성일: 2026-08-03
상태: 구성 확정 · 프롬프트 팩 작성 완료 · 생성 전 사용자 리뷰 대기

## 1. 개요

한국을 여행하는 **일본인 관광객** 대상 **Toss for Travelers(Visitor 서비스)** 홍보 릴스.
세로 9:16, 30초, 13컷. 맥도날드 재팬 인스타 릴스 第二話「踏切」篇의 **연출 구조를 이식**한 오리지널.
토스 Foreigner Bridge Crew 2기 공모전 출품 대비.

**핵심 메시지 (단 하나):**

> 이 카드, 버스도 지하철도 된다. (교통카드로도 쓸 수 있다)

**한 줄 시놉시스:**

여름 서울, 정류장에서 버스를 기다리는 후배 둘. 버스가 들어오는데 **창문 너머에 선배가 앉아 있다.**
선배는 토스 카드를 들어 보이며 "이거 버스도 돼!"를 몸짓으로 설명하려 하지만, 유리와 엔진음에 막혀
목소리가 닿지 않는다. **문 닫힘 경고음이 울리기 시작하고**, 설명을 끝내지 못한 채 버스와 함께 사라진다.
텅 빈 정류장에 남은 정적 — 그리고 **선배가 못 끝낸 설명을 광고가 대신 마무리한다.**

## 2. 이번 산출물의 범위

- 산출물은 **프롬프트 문서뿐**이다. 이미지·영상 생성은 하지 않는다.
- 오디오 제작, 자막 번인, 어셈블리, 최종 렌더는 **이후 별도 단계**.
- 프롬프트는 **도구 비의존적**으로 작성한다.

## 3. 레퍼런스 구조의 이식

### 원작「踏切」篇의 구조

1. 귀여운 선배가 후배들에게 버거를 같이 먹자고 하고 싶다
2. 하지만 열차가 와서 **건널목 차단기가 내려가 있다**
3. 기다리는 동안 치즈 등 제품의 매력을 **몸짓과 소리로 귀엽게** 전달한다
4. **열차가 지나가는 화면에서 제품 광고**
5. 열차가 다 가버리자 카메라 앞으로 다가와 "같이 먹자" → 먹는 장면

### 차단기의 진짜 기능

차단기는 낭만적 장애물이 아니다. **말이 안 통하게 만들어 몸짓을 강제하는 장치**다.
목소리가 닿지 않으니 제품을 몸짓과 소리로 전달할 수밖에 없고, 거기서 귀여움과 웃음이 나온다.
이것이 이 광고의 엔진이며, 우리가 반드시 가져와야 하는 것이다.

### 우리식 치환

| 원작 | 우리 |
|---|---|
| 건널목 차단기 | **버스 창문** (유리 + 엔진음이 목소리를 막는다) |
| 열차를 기다리는 강제된 시간 | **버스가 정류장에 서 있는 시간** |
| 「띵띵띵」 건널목 경보음 | **문 닫힘 경고음 「ピピピピ」** (4중 레이어 — 아래 5절) |
| 치즈를 몸짓으로 | **카드를 들어 보이고 → 단말기에 태그** |
| 열차가 화면을 덮으며 제품 광고 | **버스가 떠난 뒤 페이드아웃 → 제품 인서트** |
| 차단기 열림 → 같이 먹자 | **버스와 함께 사라짐 → 텅 빈 정류장의 정적** (개그 착지) |

**긴장의 방향이 뒤집혔다.** 원작은 열차가 *다가오며* 긴장을 만들지만, 우리는 버스가 *떠나려 하며*
만든다. 다급함이 더 크고, "설명을 끝내지 못했다"는 결말이 자연스럽게 나온다.

**장소를 한국으로 바꾼 이유:** 건널목은 일본성의 기호다. 우리 전제는 "일본인이 **한국을** 여행한다"
이므로 배경이 일본처럼 읽히면 전제가 무너진다. 서울 도심 정류장과 시내버스는 한국임이 즉시 읽히고,
버스라서 교통 소구와도 직결된다.

## 4. 단일 메시지와 가이드 정합성

핵심 메시지 = **"교통카드로도 된다"**. 가이드 추천 각도 중 다음에 해당한다.

> **Payment + transportation:** 결제와 대중교통을 카드 한 장으로 해결

**이 편은 교통에만 집중한다.** 매장 결제 장면은 넣지 않는다 — 기능 나열형으로 흐르는 것을 막기 위해서다.
"결제 카드인데 교통카드로도 된다"는 사실은 카피의 조사(「も」/"도")로만 전달한다.

### 이 컨셉에서 특별히 주의할 점

| 위험 | 대응 |
|---|---|
| 버스 단말기에 티머니 등 **타사 로고**가 생성될 수 있다 | 단말기는 **무브랜드**. 초록 픽토그램만. 로고·문자 생성 금지 |
| 버스 노선번호·회사명이 생성될 수 있다 | 버스 외부 문자는 **판독 불가**하게. 노선번호·행선지 표기 금지 |
| "모든 교통수단에서 된다"로 읽힐 수 있다 | 각주로 **"티머니를 지원하는 지하철·버스"** 범위 명시 |
| 선배가 말하는 내용을 자막으로 번역하면 개그가 죽는다 | **자막으로 대사를 옮기지 않는다.** 「（聞こえない）」처럼 안 들림을 살린다 |

## 5. 긴장감 설계 (원작 「띵띵띵」의 대응)

한국 시내버스의 실제 사운드를 4중으로 겹쳐 카운트다운을 만든다.

| 순서 | 소리 | 역할 |
|---|---|---|
| 도착 | 에어브레이크 「プシュー」 | 정지 — 시간이 시작된다 |
| 대기 | 공회전 진동음 (낮게 깔림) | 배경 압력 |
| **긴장** | **문 닫힘 경고음 「ピピピピ…」** | **띵띵띵의 직접 대응.** 카운트다운 시작 |
| 임박 | 에어브레이크 재분사 + 엔진 회전수 상승 | 출발 임박 |
| 출발 | 문 닫히는 「プシュッ」 + 「ブロロ…」 | 종료 |

**시각적 틱을 겹친다:** 깜빡이는 문 램프, 방향지시등.
**편집 리듬을 조인다:** 컷 길이를 2초 → 1.5초 → 1초 → 0.5초로 점점 짧게.

**소리의 대비가 개그를 만든다:** 선배의 말은 유리에 막혀 웅얼거림으로만 들리는데,
**단말기 태그음 「삑」만은 열린 문으로 선명하게 건너온다.** 말은 안 들리는데 태그 소리는 들리는
대비가 귀엽고, 동시에 "교통카드로 된다"를 실증한다.

## 6. 제품 정보 (표현 정확성 기준)

Toss for Travelers - Visitor 서비스는 한국을 방문한 외국인을 위한 **선불 결제 서비스**다.

- **여권만으로 가입** — ARC·한국 은행 계좌 불필요
- **첫 Visitor 카드 무료**
- **티머니 기능 포함** — 티머니를 지원하는 지하철·버스에서 사용 ← **이 편의 소구점**
- 한국의 카드결제 가능 매장에서 사용
- 토스머니를 충전해 사용

### 표현 금지/허용 대조

| 이렇게 | 이렇게 쓰지 않는다 |
|---|---|
| 티머니 기능으로 지하철·버스를 이용할 수 있어요 | 모든 교통수단에서 조건 없이 쓸 수 있어요 |
| 여권만 있으면 가입할 수 있어요 | 가입하려면 ARC가 필요해요 |
| 첫 Visitor 카드는 무료예요 | 모든 발급·재발급이 항상 무료예요 |
| **선불카드**예요 | 신용카드·체크카드예요 |

**수치·과장 금지:** "1분 만에", "3초면" 등 검증되지 않은 수치 금지.
"무조건", "100%", "최고의", "다 됩니다" 금지.
**계열사 금지:** 토스뱅크 등 계열사 언급 금지. 브랜드명은 **'토스' / toss**로만.

## 8. 고정 자산

### 인물 A — 선배 (주인공, 버스 안)

- 일본인 여성, 20대 중반. **밝고 귀여운 에너지.** 표현이 크지만 과장되지 않게
- 다크브라운 세미롱 웨이브, 가벼운 시스루 뱅
- **아이보리 반소매 블라우스**, **코랄 크로스백 스트랩**
- 버스 창가에 앉아 있다가 몸을 일으켜 창문에 붙는다

### 인물 B·C — 후배 2명 (정류장)

- 같은 또래~약간 어린 일본인 여성 2명
- 담색 여름 옷 (연베이지·라이트블루). 선배보다 시각적 비중 낮게
- 표정은 "어리둥절 → 집중 → 허탈"의 순서로 간다

### 로케이션

- **서울 도심 버스 정류장** (횡단보도 인접), 여름 낮, 자연광
- **파란 시내버스** (간선버스). **노선번호·행선지·회사명 문자는 판독 불가하게**
- 버스 내부: 앞문 근처, 옆에 카드 단말기(무브랜드)

### 제품 — Toss Visitor 카드

- 원본: `assets/toss-card/pre-card-hologram-front (1).png` (블루 홀로그램 전면, **세로형**)
- 보조: `assets/toss-card/hand-pre-card-hologram.png`
- **카드 등장 컷(S05·S06·S07·S08)은 원본을 레퍼런스로 첨부** + "로고·문자 재그리기 금지" 명시
- 카드 최초 노출은 **S05**
- **S12 제품 인서트는 카드를 생성하지 않는다** — 배경 플레이트만 만들고 원본 PNG를 컷아웃으로 합성

## 9. 컷 구성 요약 (13컷 / 30초)

| 컷 | 시간 | 내용 |
|---|---|---|
| S01 | 0–2s | 여름 서울, 정류장에서 버스를 기다리는 후배 2명 |
| S02 | 2–4s | 버스가 슥 들어온다 |
| S03 | 4–6s | 문이 열리고 — **창문 너머에 선배가 있다.** 눈이 마주친다 |
| S04 | 6–8s | 선배가 창문에 붙어 열심히 설명. 목소리는 안 들린다 |
| S05 | 8–10s | **토스 카드를 자랑스럽게 들어 보인다** (제품 첫 노출) |
| S06 | 10–12s | 카드 → 버스 → 후배들 순서로 가리킴 |
| S07 | 12–14s | **단말기에 카드를 찍는다 → 「삑」.** 엄지 척 |
| S08 | 14–16s | **문 닫힘 경고음 시작.** 다급해진다 |
| S09 | 16–17s | 문이 닫힌다. 유리에 붙어 마지막으로 외친다 |
| S10 | 17–19s | 버스 출발. 창문 너머로 멀어지며 **여전히 설명 중** |
| S11 | 19–21s | 텅 빈 정류장. 후배 둘만 남아 멍하니. **정적** ★개그 착지 |
| S12 | 21–26s | **페이드아웃 → 제품 인서트.** 카드 + 카피 + 각주 |
| S13 | 26–30s | 후배들이 폰을 꺼낸다 (실제 앱 화면) + 로고 + 워터마크 + CTA |

**S13을 넣은 이유:** 가이드가 "마지막에 가입·확인 등 다음 행동을 알려줘요"를 요구한다.
원작은 제품 광고로 끝나지만, 후배들이 폰을 꺼내는 4초를 붙이면 CTA가 해결되고
"설명을 들은 사람이 실제로 움직였다"는 마무리도 된다.
