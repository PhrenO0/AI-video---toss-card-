# TOSS 외국인 선불카드 일본 타깃 AI 릴스 제작 전략

## 1. 목표

- 일본인 여성 관광객이 서울 지하철 개찰구에서 겪는 짧은 오해를 축구 심판 개그로 풀어낸다.
- 대사 없이도 이해되는 9:16 세로형 광고로 제작한다.
- 러닝타임은 14.5초 전후, 1080×1920, 30fps를 기준으로 한다.
- 실제 TOSS 선불카드 에셋을 제품 히어로 컷과 엔드카드에 그대로 사용한다.

## 2. 크리에이티브 원칙

1. 첫 번째 `ピッ、ピッ！`은 개찰구 오류음처럼 들리지만 실제로는 축구 심판의 짧은 호루라기다.
2. 같은 소리가 심판 등장과 함께 반복되면서 관객이 개그를 이해한다.
3. 심판은 끝까지 진지하고 무표정해야 한다. 코미디는 과장이 아니라 상황의 부조리에서 나온다.
4. 일본어 의성어와 카피는 AI 영상 안에서 생성하지 않고 후반 합성한다. 글자 깨짐과 한글 혼입을 방지하기 위해서다.
5. TOSS 카드는 생성형 모델에만 맡기지 않는다. 실제 PNG를 카드 히어로 컷과 마지막 화면에 합성해 로고·칩·색을 보존한다.

## 3. 14.5초 타임라인

| 시간 | 화면 | 소리/자막 | 역할 |
|---|---|---|---|
| 0.0–0.8초 | 깨끗한 서울 지하철 개찰구 와이드, 여성 관광객 진입 | 주변음만 | 1초 안에 장소 설명 |
| 0.8–2.7초 | 일반 교통카드 태그, 개찰구 빨간 X | 실제 심판 휘슬 두 번 `ピッ、ピッ！` | 오해를 만드는 훅 |
| 2.7–3.7초 | 관광객 얼굴 클로즈업, 시선은 카드와 개찰구 | `え？` | 반응 비트 |
| 3.7–6.1초 | 다른 복도 방향에서 심판 등장, 휘슬을 다시 두 번 붐 | 동일한 `ピッ、ピッ！` | 소리의 정체 공개 |
| 6.1–8.5초 | 심판이 무표정으로 성큼성큼 접근 | `コツ、コツ` | 긴장과 코미디 축적 |
| 8.5–10.6초 | 심판이 프레임에 들어와 카드를 레드카드처럼 높이 듦 | `シャキーン！` | 제품 공개 |
| 10.6–12.5초 | 실제 TOSS 카드로 태그, 개찰구 초록 화살표 | `ピロン♪` | 문제 해결 |
| 12.5–14.5초 | 카드 히어로 + 관광객의 안도 미소/가벼운 목례 | `韓国の交通カードは、TOSSで。` | 브랜드 회수 |

작은 한국어 보조 카피: `한국 여행, 교통카드는 TOSS로.`

## 4. 힉스필드 생성 구조

### 캐릭터 잠금

- 현재 여성 캐릭터 시트(`bc087...png`)는 최종 스토리보드와 헤어·의상·하의·가방이 다르므로 그대로 쓰지 않는다.
- 최종 여성 기준은 `장소와 인물.png`와 `스토리 1.png` 속 인물로 통일한다.
- 최종 심판 기준은 `장소와 인물.png`의 얼굴/무표정과 `b55b...png`의 체형·유니폼 정보를 결합한다.
- 새 여성/심판 잠금 스틸을 GPT Image 2 2K High로 먼저 생성하고, 얼굴과 의상 승인 후 영상에 참조한다.

### 영상 생성

- 모델: Higgsfield `Seedance 2.0`
- 포맷: 9:16, 1080p, standard mode, high bitrate, comedy genre, 네이티브 오디오 끔
- 생성 단위: 5초 클립 3개
  1. 실패 태그 + 관광객 반응
  2. 심판 등장 + 접근 + 카드 꺼내기
  3. 카드 선언 + 성공 태그 + 엔드 전환
- 각 클립은 시작 스틸과 캐릭터/제품 레퍼런스를 함께 사용한다.
- 후반 편집에서 14.5초로 압축하고 실제 휘슬·발걸음·성공음과 일본어 자막을 타이밍에 맞춰 넣는다.

## 5. 예상 크레딧

현재 잔액: **1,162 크레딧 (Plus)**

| 항목 | 예상 크레딧 |
|---|---:|
| 캐릭터/장면 잠금 스틸 5장 × 7 | 35 |
| Seedance 2.0 5초 × 3클립 | 135 |
| 합계 | 약 170 |

선택적 저비용 모션 테스트는 Seedance 2.0 Mini 5초 × 3클립으로 37.5크레딧이다. 테스트 후 풀품질로 재생성하면 전체 예산은 약 207.5크레딧이다.

## 6. 생성 전 확정할 한 가지

추천 최종 카피는 `韓国の交通カードは、TOSSで。`이다. 더 여행 광고답게 만들고 싶다면 `韓国旅行、交通カードはTOSSで。`로 바꿀 수 있다.

본 전략 승인 후 순서는 `캐릭터 잠금 스틸 → 3개 장면 스틸 → Mini 모션 테스트 → 풀품질 영상 → 14.5초 편집/효과음/카피 합성 → 검수`이다.
