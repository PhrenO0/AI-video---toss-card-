### @WOWPASS_JAPAN — 혜택·프로모션형 기준

2026-08-10 뷰티세트 게시물은 다음 정보를 한 번에 완결했다.

- 대상: 8월 서울 방문 예정자
- 혜택: 인기 K-뷰티 브랜드 상품 묶음
- 가치와 실부담: 상품 가치와 배송비를 분리 표기
- 대상 기간: 서울 체류 기간을 날짜로 명시
- 절차: 출국 전 신청 → 희망 배송일 선택 → 서울 숙소 수령
- 사용 장면: 화장품을 찾으러 다닐 시간이 부족한 여행자

## #1 첫 카드 무료 · Free card

**원리** 숫자형 훅 — 첫 줄에 구체적 숫자와 혜택을 동시에

```
1枚目は無料です💳

「Toss Visitorカード」は、トスマネーをチャージして使うプリペイドカードです。
最初の1枚は発行料がかかりません。

カード代を払わずに、韓国での支払いを始められます✨

#韓国旅行 #ソウル旅行 #韓国決済 #PR
```

**한국어** 1장째는 무료입니다 / 「Toss Visitor 카드」는 토스머니를 충전해서 쓰는 선불카드입니다 /
첫 1장은 발급료가 들지 않습니다 / 카드값을 내지 않고, 한국에서의 결제를 시작할 수 있습니다

**이미지** ① `애셋` 카드 정면 ② `촬영` 손에 든 카드 ③ `캡처` 발급료 무료 표시 화면 ④ `촬영` 카드+여권 (여권 정보면 가림)

**주의** `最初の1枚` 한정 필수. `プリペイドカード` 명시 필수.

## #2 여권만 · Passport only

**원리** 통념 반박형 — 상대의 기존 지식을 먼저 인정하고 뒤집기

```
韓国のペイアプリ、旅行者は使えないと思っていませんか🛬

たしかに多くのサービスは、韓国の銀行口座や外国人登録証(ARC)が必要です。

「Toss Visitorカード」はパスポートだけで申し込めるプリペイドカードです。
最初の1枚は無料です✨

みなさんは韓国で何を使っていますか？

#韓国旅行 #ソウル旅行 #韓国決済 #PR
```

**한국어** 한국 페이 앱, 여행자는 못 쓴다고 생각하고 계시지 않나요 / 확실히 많은 서비스는 한국 은행 계좌나
외국인등록증(ARC)이 필요합니다 / 「Toss Visitor 카드」는 여권만으로 신청할 수 있는 선불카드입니다 /
첫 1장은 무료입니다 / 여러분은 한국에서 무엇을 쓰고 계신가요?

**이미지** ① `촬영` 여권만 놓인 컷 ② `캡처` 여권 인증 단계 ③ `캡처` 발급 완료 ④ `캡처` 일본어 UI *(지원 확인 후, 미지원이면 카드 실물로 대체)*

**주의** 전화번호는 언급하지 않음 — 가이드에 명시가 없어 단정 불가.

## #3 교통 통합 · Payment + transportation

**원리** 실수 방지 팁 — "유용함"을 각인시켜 저장을 부름

```
地下鉄もバスも、この1枚でタッチ🚇

「Toss Visitorカード」にはT-money機能が入っています。
T-money対応の地下鉄やバスで、そのまま使えます。

決済カードと交通カードを2枚持たなくて済みます。

降りるときのタッチもお忘れなく✨

#ソウル旅行 #韓国交通 #Tmoney #PR
```

**한국어** 지하철도 버스도, 이 한 장으로 태그 / 「Toss Visitor 카드」에는 티머니 기능이 들어 있습니다 /
티머니를 지원하는 지하철과 버스에서 그대로 쓸 수 있습니다 / 결제카드와 교통카드를 두 장 들고 다니지
않아도 됩니다 / 내릴 때 태그도 잊지 마세요

**이미지** ① `촬영` 개찰구 태그 순간 ② `촬영` 버스 단말기 ③ `촬영` 지갑에 카드 한 장 ④ `캡처` 티머니 잔액 화면

**주의** `T-money対応の` 한정 필수 — 빠지면 "모든 교통수단 조건 없이"가 되어 금지 표현.

**확인 불필요 — 지금 발행 가능**

## #4 사용처 · Pay anywhere

**원리** 부정형 훅 — 예상되는 오해를 첫 줄에서 깸

```
提携店だけ、ではありません🏪

「Toss Visitorカード」は、韓国でカード払いができるお店ならどこでも使えます。

コンビニ、カフェ、食堂、ショッピング。
旅行中によく行く場所は、だいたいカバーされます✨

#韓国旅行 #ソウル旅行 #韓国決済 #PR
```

**한국어** 제휴점만, 이 아닙니다 / 「Toss Visitor 카드」는 한국에서 카드결제가 되는 가게라면 어디서든
쓸 수 있습니다 / 편의점, 카페, 식당, 쇼핑 / 여행 중 자주 가는 곳은 대체로 커버됩니다

**이미지** 본문 4개 장소와 1:1 대응 — ① `촬영` 편의점 ② `촬영` 카페 ③ `촬영` 식당 ④ `촬영` 쇼핑 매장 결제 순간

**주의** `カード払いができるお店なら` 조건 필수 — 현금만 받는 가게가 있음.
본문 나열과 이미지 순서를 일치시킨 것은 알고리즘의 텍스트·이미지 주제 일치 평가를 노린 설계.

## #5 카드 거절 · 반론 대응

**원리** 고민 대변형 + 마지막 질문. X에 실제로 올라온 반론을 본문에 인용

```
韓国でカードが弾かれた経験、ありませんか💦

海外発行のカードは、お店によって通らないことがあります。
「全部クレカでいける」と思っていると、レジの前で困ることも。

韓国で発行するプリペイドカードなら、カード払いができるお店でそのまま使えます✨

どこで弾かれましたか？よかったら教えてください。

#韓国旅行 #ソウル旅行 #韓国決済 #PR
```

**한국어** 한국에서 카드가 거절당한 경험, 없으신가요 / 해외 발행 카드는 가게에 따라 안 되는 경우가 있습니다 /
"전부 신용카드로 되겠지"라고 생각하다가 계산대 앞에서 곤란해지기도 합니다 / 한국에서 발행하는 선불카드라면,
카드결제가 되는 가게에서 그대로 쓸 수 있습니다 / 어디서 거절당하셨나요? 괜찮으시면 알려주세요

**이미지** ① `촬영` 재래시장 노점 ② `촬영` 개인 카페 계산대 ③ `촬영` 정상 결제 순간 ④ `제작` 대비 그래픽 (`03-comparison.svg`)

**메모** 「全部クレカでいける」는 실제 X 포스트에 있던 문장.
**이 반론에 답하지 않으면 나머지 포스트가 전부 무의미해진다.**

**확인 불필요 — 지금 발행 가능**

## #6 잔액 · 불안 해소

**원리** 질문형 훅 + 리플 유도. 답하기 쉬운 질문이라 장벽이 낮음

```
使い切れなかった残高、消えません🪙

「Toss Visitorカード」のトスマネーは、旅行が終わってもそのまま残ります。
次に韓国へ来たとき、また使えます✨

年に何回、韓国に行きますか？

#韓国旅行 #ソウル旅行 #PR
```

**한국어** 다 못 쓴 잔액, 사라지지 않습니다 / 「Toss Visitor 카드」의 토스머니는 여행이 끝나도 그대로 남습니다 /
다음에 한국에 왔을 때 다시 쓸 수 있습니다 / 1년에 몇 번, 한국에 가시나요?

**이미지** ① `캡처` 잔액 화면 (금액 마스킹) ② `촬영` 지갑 속 카드 ③ `촬영` 공항 게이트·기내 창밖 ④ `제작` 이월 그래픽 (`04-balance-carryover.svg`)

**주의** 가이드가 명시한 "다음 방문 때 다시 사용 가능"만 사용.
**출금·환불은 한 글자도 넣지 않음** — 충전수단에 따라 달라 단정 금지 영역.
리플로 환불을 물어보면 "최신 앱 안내를 확인해달라"고만 답한다.

## #7 공항 30분 · Travel essential

**원리** "고민되면 저장" 수법 + 하우투. 제품이 5단계 중 하나로만 등장해 광고 느낌이 사라짐

```
仁川空港に着いてからの30分、これだけ📌

①入国審査
②預けた荷物を受け取る
③SIM・eSIMを準備
④「Toss Visitorカード」を用意   ← [확인] 用意 / 受け取る / 申し込む
⑤空港鉄道でソウル市内へ

保存しておくと当日あわてません✨

#仁川空港 #韓国旅行 #ソウル旅行 #空港鉄道
```

**한국어** 인천공항에 도착하고 나서의 30분, 이것만 / ①입국심사 ②맡긴 짐 찾기 ③SIM·eSIM 준비
④「Toss Visitor 카드」를 [준비] ⑤공항철도로 서울 시내로 / 저장해두면 당일 허둥대지 않습니다

**이미지** 시간 순서대로 — ① `촬영` 도착 로비 안내 표지판 ② `촬영` 수하물 수취대 ③ `촬영` 공항철도역 입구 ④ `제작` 5단계 체크리스트 카드 (`01-airport-checklist.svg`)

⚠️ **입국심사 구역은 촬영 제한.** 심사대·보안구역을 찍지 말고 안내 표지판으로 대체.

**확인 필요** ④의 동사 — 실물 카드 수령 방법이 확정되면 교체.
공항철도 요금·소요시간을 본문에 넣을 경우 공식 사이트에서 재확인.

## #8 조건분기 · 선택 가이드

**원리** 조건분기형 「이런 사람 → 이 답」. 읽는 사람이 자기를 대입할 수 있어 저장·리포스트가 가장 잘 붙음

```
どのカードを持っていくか迷ったら📌

▶︎荷物を増やしたくない
　→ 決済と交通が1枚になっているもの

▶︎現地でカードが弾かれるのが不安
　→ 韓国で発行するもの

▶︎最初にお金をかけたくない
　→ 発行料がかからないもの

「Toss Visitorカード」は、この3つに当てはまります✨

#韓国旅行 #ソウル旅行 #韓国決済 #PR
```

**한국어** 어느 카드를 가져갈지 고민된다면 / ▶︎짐을 늘리고 싶지 않다 → 결제와 교통이 한 장으로 된 것 /
▶︎현지에서 카드가 거절당할까 불안하다 → 한국에서 발행하는 것 / ▶︎처음에 돈을 들이고 싶지 않다 →
발급료가 들지 않는 것 / 「Toss Visitor 카드」는 이 세 가지에 해당합니다

**이미지** ① `제작` 조건분기 카드 (`02-choice-branches.svg`) ② `촬영` 지갑 속 카드 한 장 ③ `촬영` 결제 순간 ④ `애셋` 카드 실물

**메모** 제품을 **마지막 한 줄에만** 놓은 것이 핵심. 앞 세 줄은 순수한 선택 기준이라
광고로 읽히지 않고 읽는 사람이 스스로 결론에 도달한다.

**확인 불필요 — 지금 발행 가능**

## #10 충전 · 보류

⛔ **확인 전 발행 금지**

가이드의 해외간편결제 목록에 **일본 결제수단이 없다.** 계좌이체는 한국 계좌 필요.
편의점 현금 충전이 유일한 경로로 보이는데, 그건 **원화 현금이 필요하다**는 뜻이다.
`両替不要`로 읽히는 문장을 쓰면 즉시 가이드 위반.

## 통합 촬영 리스트

포스트마다 따로 나가지 않는다. **반나절 두 번**으로 10건이 전부 커버된다.
