# 비트시트 — 컷별 연출 설계 (13컷 / 30초)

전제: [visual-grammar.md](./visual-grammar.md)의 문법을 전 컷에 적용한다.
특히 **전경 보케 프레이밍**과 **유리를 사이에 둔 촬영**이 이 편의 두 축이다.

## 전체 리듬 — 조여들다가 툭 끊긴다

| 구간 | 컷 | 역할 | 컷 길이 |
|---|---|---|---|
| 도입 | S01–S03 | 정류장 → 버스 도착 → 선배 발견 | 2초씩 (여유) |
| 설명 | S04–S07 | 몸짓으로 카드를 설명한다 | 2초씩 (리듬 유지) |
| **압박** | S08–S10 | 경고음 시작 → 문 닫힘 → 출발 | **2 → 1 → 2초 (조여든다)** |
| 착지 | S11 | 텅 빈 정류장. 정적 | 2초 (길게 느껴진다) |
| 광고 | S12–S13 | 제품 인서트 → CTA | 5초 + 4초 |

**설계 의도:** S08부터 컷이 짧아지고 경고음이 겹치며 압박이 올라간다. S10에서 버스가 떠나면
소리가 한꺼번에 빠지고, **S11의 정적이 웃음의 착지점**이 된다. 이 정적을 충분히 주는 것이 중요하다.

## 긴장감 4중 레이어 (원작 「띵띵띵」의 대응)

| 시점 | 소리 | 시각 |
|---|---|---|
| S02 | 에어브레이크 「プシュー」 | 버스가 멈추며 차체가 살짝 주저앉는다 |
| S03–S07 | 공회전 진동음 (낮게 깔림) | — |
| **S08** | **문 닫힘 경고음 「ピピピピ…」** | **문 램프가 깜빡인다** |
| S09 | 에어브레이크 재분사 + 엔진 회전수 상승 | 방향지시등 점멸 |
| S10 | 문 닫히는 「プシュッ」 + 「ブロロ…」 | 버스가 미끄러져 나간다 |
| S11 | **전부 빠지고 도심 앰비언스만** | 텅 빈 정류장 |

**소리의 대비가 개그를 만든다:** 선배의 말은 유리에 막혀 웅얼거림으로만 들리는데,
**S07의 태그음 「삑」만은 열린 문으로 선명하게 건너온다.**

## S01 · 0.0–2.0s — 정류장에서 기다리는 후배 둘

| 항목 | 설계 |
|---|---|
| 카메라 | 미드 투샷. 35–50mm, 눈높이. 고정 |
| 프레이밍 | 후배 2명이 **화면 왼쪽~중앙**. 오른쪽은 차도 방향으로 비워둔다 (버스가 들어올 자리) |
| 전경 보케 | 정류장 기둥·표지판을 좌측에 크게 흐리게 |
| 조명 | 여름 정오 직후 자연광. 밝고 통풍감 있게 |
| 동작 | 한 명은 폰을 만지작, 한 명은 차도 쪽을 본다. 살짝 지루한 기색 |
| 오디오 | 도심 앰비언스 (차량·매미·먼 신호음) |
| 자막 | 없음 |
| 의도 | 장소와 인물을 2초에 세팅. 오른쪽 여백이 다음 컷의 등장을 예고한다 |

## S02 · 2.0–4.0s — 버스가 슥 들어온다

| 항목 | 설계 |
|---|---|
| 카메라 | 후배들 어깨 너머로 차도를 본다. 35mm. 버스가 프레임 오른쪽에서 들어와 멈춘다 |
| 조명 | 버스 차체에 하늘이 반사되며 밝게 흐른다 |
| 동작 | 파란 시내버스가 미끄러져 들어와 정지. 차체가 살짝 주저앉는다 |
| ⚠️ 컴플라이언스 | **노선번호·행선지·회사명 문자 생성 금지.** 판독 불가하게 |
| 오디오 | 버스 접근음 → **에어브레이크 「プシュー」** |
| 자막 | 없음 |

## S03 · 4.0–6.0s — 창문 너머에 선배가 있다

| 항목 | 설계 |
|---|---|
| 카메라 | 버스 창문 쪽으로 컷인. 50mm. 창문 프레임이 화면을 구획한다 |
| 프레이밍 | **선배는 화면 오른쪽(버스 안).** 이 좌우 관계를 끝까지 유지한다 |
| 유리 | 하늘·가로수 반사가 유리 위로 흐른다. **표정은 반드시 읽힌다** |
| 동작 | 선배가 후배들을 발견하고 눈이 커진다 → 창문 쪽으로 몸을 기울인다 |
| 표정 | 반가움. 밝지만 과장 없이 |
| 오디오 | 공회전 진동음이 깔린다. 문 열리는 소리 |
| 자막 | 없음 (놀람은 표정으로) |

## S04 · 6.0–8.0s — 열심히 설명하지만 안 들린다

| 항목 | 설계 |
|---|---|
| 카메라 | 유리 너머 선배의 미드클로즈. 50–85mm. 고정 |
| 유리 | 손바닥을 유리에 붙인다 — 접촉이 귀여움을 만든다 |
| 동작 | 입을 열심히 움직이며 뭔가 설명한다. 손이 같이 바쁘다 |
| ⚠️ 소리 | **목소리는 유리에 막혀 웅얼거림으로만.** 대사를 알아들을 수 없어야 한다 |
| 오디오 | 유리에 먹힌 웅얼거림 + 공회전 |
| 자막 | 「（聞こえない）」 / 한국어 「（안 들려요）」 — **대사를 번역하지 않는다** |
| 의도 | 몸짓이 강제되는 이유를 여기서 확립한다. 이게 이 광고의 엔진 |

## S05 · 8.0–10.0s — 카드를 자랑스럽게 들어 보인다

| 항목 | 설계 |
|---|---|
| 카메라 | 정면 미드샷. 85mm, 눈높이. 고정 |
| 프레이밍 | 얼굴 상단 1/3, **카드 중앙 1/3.** 얼굴과 카드가 한 프레임에 |
| 포즈 | 유리 안쪽에서 **카드를 세로로, 전면을 카메라로** 향하게 든다 |
| 표정 | "이거야!" 하는 밝은 자부심 |
| 유리 | 카드 위 반사는 최소화 — **카드면이 선명해야 한다** |
| ⚠️ 제품 | **카드 원본 에셋 첨부 필수. 로고·문자 재그리기 금지** |
| 오디오 | 공회전. 음악이 살짝 올라온다 |
| 자막 | 없음 (카드가 말한다) |
| 의도 | 제품 최초 노출. 레퍼런스의 히어로 제스처를 그대로 계승 |

## S06 · 10.0–12.0s — 카드 → 버스 → 후배들 가리키기

| 항목 | 설계 |
|---|---|
| 카메라 | 미드샷 유지. 손 동작이 프레임에 다 들어오게 살짝 넓게 |
| 동작 | ① 카드를 가리킨다 → ② 버스 천장·차내를 가리킨다 → ③ 후배들을 가리킨다. **한 번에 하나씩 명확하게** |
| 표정 | 눈을 크게 하며 "알겠어?" |
| 오디오 | 공회전. 웅얼거림 |
| 자막 | 없음 또는 아주 작게 |
| 의도 | "이 카드 = 이 버스 = 너희도" 를 말 없이 전달 |

## S07 · 12.0–14.0s — 단말기에 찍는다 → 「삑」

| 항목 | 설계 |
|---|---|
| 카메라 | 선배의 손과 단말기가 함께 보이는 미드클로즈. 50mm. 열린 앞문 쪽에서 |
| 동작 | 카드를 단말기에 태그 → 초록 픽토그램 점등 → **엄지 척** |
| ⚠️ 단말기 | **무브랜드.** 티머니 등 어떤 로고·문자도 생성 금지. **초록 픽토그램만** |
| ⚠️ 소리 | **태그음 「삑」만은 열린 문으로 선명하게 건너온다** — 이 대비가 개그의 핵 |
| 오디오 | 「삑」 (선명) + 공회전 |
| 자막 | SFX 자막 「ピッ！」 (귀여운 손글씨풍) |
| 의도 | "교통카드로 된다"를 몸짓 안에서 실증. 이 컷이 메시지를 증명한다 |

## S08 · 14.0–16.0s — 문 닫힘 경고음 시작

| 항목 | 설계 |
|---|---|
| 카메라 | 선배 미드샷 ↔ 후배들 리액션 컷백 (짧게 두 번) |
| 시각 | **문 램프가 깜빡인다.** 컷이 짧아지기 시작한다 |
| 동작 | 선배가 다급해져 설명을 서두른다. 후배들은 어리둥절 |
| 오디오 | **문 닫힘 경고음 「ピピピピ…」** 시작 — 원작 「띵띵띵」의 대응 |
| 자막 | SFX 자막 「ピピピピ…」 |
| 의도 | 여기서부터 카운트다운. 편집 리듬을 조인다 |

## S09 · 16.0–17.0s — 문이 닫힌다 (1초)

| 항목 | 설계 |
|---|---|
| 카메라 | 타이트하게. 유리에 붙은 선배의 얼굴과 손 |
| 동작 | 문이 닫힌다. 선배가 유리에 붙어 마지막으로 뭔가 외친다 — 이제 완전히 안 들린다 |
| 오디오 | 「プシュッ」 + 엔진 회전수 상승. 목소리는 더 멀어진다 |
| 자막 | 없음 (다급함만) |
| 의도 | **가장 짧은 컷.** 리듬의 정점 |

## S10 · 17.0–19.0s — 버스 출발, 여전히 설명 중

| 항목 | 설계 |
|---|---|
| 카메라 | 고정. 버스가 프레임을 왼쪽으로 빠져나간다. **창문이 흘러가며 모션 블러** |
| 동작 | 멀어지는 창문 너머로 선배가 **아직도 설명하고 있다** (이게 웃음 포인트) |
| 조명 | 차체 반사가 밝게 흐르며 지나간다 |
| 오디오 | 「ブロロ…」 엔진음이 멀어진다 |
| 자막 | 없음 |
| 의도 | 설명을 끝내지 못했다는 것을 시각적으로 확정 |

## S11 · 19.0–21.0s — 텅 빈 정류장 ★개그 착지

| 항목 | 설계 |
|---|---|
| 카메라 | S01과 거의 같은 프레이밍의 미드 투샷. **버스가 사라진 오른쪽 여백이 비어 있다** |
| 동작 | 후배 둘만 남아 버스가 간 쪽을 멍하니 본다. 서로를 한 번 본다 |
| 표정 | 허탈함. 작게 눈을 마주친다 |
| 오디오 | **모든 버스 소리가 빠지고 도심 앰비언스만.** 정적을 충분히 |
| 자막 | 「…」 정도 |
| 의도 | **웃음의 착지점.** S01과 같은 구도로 돌아와 "아무 것도 못 들었다"가 완성된다 |

## S12 · 21.0–26.0s — 제품 인서트 (페이드아웃 후)

| 항목 | 설계 |
|---|---|
| 전환 | S11에서 **페이드아웃** → 제품 인서트로 |
| 구성 | 흐린 실사 배경(정류장·버스 보케) 위에 **카드 컷아웃 + 메인 카피 + 각주** 플랫 오버레이 |
| 레이아웃 | 레퍼런스의 그래픽 인서트 카드 구조를 계승. 카드는 중앙, 카피는 그 아래, 각주는 하단 작게 |
| ⚠️ 제품 | 카드는 **원본 에셋을 그대로 합성**한다 (생성하지 않는다) |
| 오디오 | 음악이 밝게 들어온다 |
| 자막 | 메인 카피 + 각주 (→ [copy-deck.md](./copy-deck.md)) |
| 의도 | **선배가 못 끝낸 설명을 광고가 대신 마무리한다.** 인서트에 명분이 생기는 지점 |

## S13 · 26.0–30.0s — 후배들이 폰을 꺼낸다 (CTA)

| 항목 | 설계 |
|---|---|
| 카메라 | 후배 2명 미드 투샷. 85mm. 아주 느린 푸시인 |
| 동작 | 서로를 보고 끄덕이더니 **폰을 꺼내 들여다본다.** 눈을 내리깔며 부드럽게 웃는다 |
| 화면 | **폰 화면은 빈 플레이트** → 실제 앱 화면 후반 합성 |
| 여백 | **좌상단(로고), 하단 1/5(워터마크·CTA)** 을 인물과 겹치지 않게 비운다 |
| 오디오 | 음악 마무리 + 잔향 |
| 후반 합성 | 좌상단 **공식 로고** / CTA / **디스클레이머 워터마크** / 실제 앱 화면 |
| 의도 | 가이드의 "다음 행동" 요건 충족 + 함께함 비트로 따뜻하게 닫는다 |

## 전환 설계

| 전환 | 방식 |
|---|---|
| S01→S02 | 하드컷. 시선이 차도로 향한 흐름을 잇는다 |
| S02→S03 | 하드컷. 버스 외부에서 창문 안으로 |
| S03→S04 | 하드컷 |
| S04→S05 | 하드컷. 카드가 등장하는 지점이라 톤이 밝게 올라간다 |
| S05→S06 | 하드컷 |
| S06→S07 | 하드컷. 태그음에 맞춰 |
| S07→S08 | **경고음이 먼저 들리고 화면이 따라간다** (사운드 브리지) |
| S08→S09 | 빠른 하드컷 |
| S09→S10 | 하드컷 |
| S10→S11 | 버스가 프레임을 빠져나간 직후 컷 — 소리가 한꺼번에 빠진다 |
| **S11→S12** | **페이드아웃 → 페이드인** (유일한 페이드. 개그와 광고를 분리한다) |
| S12→S13 | 부드러운 컷 |

## 오디오 총괄

- **음악:** 밝고 귀여운 여름 톤. S01–S03 절제 → S05에서 리프트 → S08에서 긴장 →
  **S11에서 완전히 멈춤** → S12에서 다시 밝게
- **SFX 순서:** 「プシュー」(S02) → 공회전(S03–S08) → **「삑」(S07, 선명)** →
  **「ピピピピ」(S08)** → 「プシュッ」+엔진(S09–S10) → **정적(S11)**
- **대사:** 알아들을 수 있는 대사는 없다. 선배의 말은 **유리에 먹힌 웅얼거림**으로만 처리한다.
  이것이 지켜지지 않으면 개그가 성립하지 않는다
- **나레이션 없음**

## 자막 규칙

- 일본어 메인 + **한국어 소자막**(작게 병기)
- **선배의 대사를 자막으로 옮기지 않는다.** 「（聞こえない）」로 안 들림을 살린다
- SFX 자막(「ピッ！」「ピピピピ…」)은 **귀여운 손글씨풍**으로 — 원작의 톤
- 하단 1/5 안전영역 안에 배치. 인물 얼굴·카드와 겹치지 않게
- **생성 이미지에는 자막을 굽지 않는다.** 전부 후반 합성
- 폰트: Noto Sans JP / Noto Sans KR (SFX는 손글씨풍 별도 폰트)
