## 연속성·제품 체크

- PASS — 관광객은 `tourist_lock_JP_v2.jpg`의 동일 인물·의상·가방·캐리어를 유지한다.
- PASS — 심판은 `referee_lock_A.png`의 동일 얼굴·유니폼·호루라기·시계를 유지한다.
- PASS — 실패는 정확히 세 번(S02, S03A, S03B)이며 모두 동일 무광 회색 일반 카드와 관광객의 오른손으로 이뤄진다. S04는 반응만이다.
- PASS — TOSS 제품은 S10에서 부분 공개, S11–S13에서만 정확한 세로 카드 한 장으로 보이며 S12·S13은 정식 PNG의 칩·타이틀·`toss` 워드마크를 식별 가능하게 유지한다.
- PASS — 공개 순서는 실패음 → 호루라기 붐업 → 심판 전신/접근 → 카드 추출 → 카드 선언 → 오른손 성공 태그 → 통과로 유지된다.
- PASS — S06·S08은 A06 축을 공유하고, S09–S13은 A05로 돌아온다. S06에는 게이트·관광객·Tracks 패널이 없다.
- PASS — S12·S13 모두 오른손 태그와 아래로 내린 왼손목 시계를 유지해 좌우 반전 오류가 없다.
